# Request access token

POST https://zoom.us/oauth/token


<h3>
Step 2: Request Access Token
</h3>



<p>
Navigate to the Auth tab and under Basic Auth and fill in the following:
</p>



<ul>


<li>
Username: [Client_ID]
</li>


<li>
Password: [Client_Secret]
</li>


</ul>



<p>
Remember, you can always use the [global variables] feature and syntax within Qodex or directly paste those values in the respective form fields if you do not wish to edit/use the global variables feature.
</p>



<p>

<strong>
Alternatively, you can clear the Auth tab fields, and use the
</strong>
 
<strong>
Headers
</strong>
 
<strong>
tab per our Zoom documentation
</strong>
.
</p>



<p>
If you go this route, make sure the Headers key-value field boxes are selected 
<u>
and
</u>
 
<a href="https://www.base64encode.org/">
Base64-encode
</a>
 your 
<code>
Client_ID:Client_Secret
</code>
 (with the colon between the two and no spaces) before pasting in the 
<code>
Authorization
</code>
 value field.
</p>



<p>
Once you&#39;re done, send the POST request to 
<code>
https://zoom.us/oauth/token
</code>
(already pre-populated in this request for you).
</p>



<p>

<strong>
If successful, the Response Body will be a JSON response containing the user&#39;s access token like the following:
</strong>

</p>
