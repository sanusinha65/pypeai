# Get a user

GET {{baseUrl}}/users/{userId}


<h3>
Get a User
</h3>



<p>
In order to get your Server-to-Server app 
<code>
access_token
</code>
, you will need your account
<u>
id. The account
</u>
id is available on your Server-to-Server app credentials page, but you can also get it programmatically.
</p>



<p>
Use the 
<q>
Get a user
</q>
 API endpoint to programmatically retrieve the account
<u>
id using another pre-created OAuth app type&#39;s `access
</u>
token`.
</p>



<p>

<strong>
This will work only if you have already authorized and authenticated Zoom API access via a pre-created OAuth app.
</strong>

</p>



<p>
The Auth tab is pre-set to Bearer Token where you can input the 
<code>
access_token
</code>
 of your choice. It will be sent in the Request Headers to the API endpoint.
</p>



<p>
If successful, you&#39;ll receive a response like this:
