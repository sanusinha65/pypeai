# Refresh access token

POST https://zoom.us/oauth/token


<h3>
Refreshing an Access Token
</h3>



<p>
Access tokens expire after one hour. Once expired, you will have to refresh a user&#39;s access token.
</p>



<p>
Take the 
<code>
refresh_token
</code>
 value you received from your 
<code>
POST request access token
</code>
 response and paste it in the 
<code>
refresh_token
</code>
 field in Body.
</p>



<p>
Navigate to the Auth tab and under 
<code>
Basic Auth
</code>
 and fill in the following:
</p>



<p>
*   Username: [Client
<u>
ID]
*   Password: [Client
</u>
Secret]
</p>



<p>
Remember, you can always use the [collection variables] feature and syntax within Qodex or directly paste those values in the respective form fields if you do not wish to edit/use the global variables feature.
</p>



<p>

<strong>
Alternatively, you can clear the Auth tab fields, and use the
</strong>
 
<strong>

<code>
Headers
</code>

</strong>
 
<strong>
tab per our Zoom documentation
</strong>
.
</p>



<p>
If you go this route, make sure to re-check the 
<code>
Headers
</code>
 key-value field boxes and 
<a href="https://www.base64encode.org/">
Base64-encode
</a>
 your 
<code>
Client_ID:Client_Secret
</code>
 (with the colon between the two and no spaces) before pasting in the 
<code>
Authorization
</code>
 value field.
</p>



<p>
Once you&#39;re done, send the POST request to 
<code>
https://zoom.us/oauth/token
</code>
 (already pre-populated in this request for you).
</p>



<p>

<strong>
Here&#39;s an example request for a refresh token:
</strong>

</p>



<pre>

<code class="plaintext">
POST /oauth/token HTTP/1.1
Host: zoom.us
Authorization: Basic base64Encode(client_id:client_secret)
Content-Type: application/x-www-form-urlencoded
refresh_token=[REFRESH TOKEN]&amp;grant_type=refresh_token


</code>

</pre>

```

```

### HEADERS
| Key | Datatype | Required | Description |
| `Authorization` | string |  | The string Basic with your Client ID and Client Secret separated with colon (:), Base64-encoded. |
| `Content-Type` | string |  |  |
