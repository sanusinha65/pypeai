# Create a Meeting

POST {{baseUrl}}/users/{userId}/meetings


<h3>
Create a Meeting with custCreate User
</h3>



<p>
CustCreate users are non-login users created via API. If you create a meeting via API, you can specify the user ID of the API user as the host. The start
<u>
url will reflect them as the meeting host when used to start the meeting—this will launch the Zoom Client. Please note the expiration time of the `start
</u>
url
<code>
parameter is **90 days** from the generation of the
</code>
start_url`.
</p>
