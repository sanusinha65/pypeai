# Update a meeting

PATCH {{baseUrl}}/meetings/:meetingId?occurrence_id=1648194360000


<p>
Use this API to update a meeting&#39;s details.
</p>



<p>

<strong>
Note:
</strong>
 
* This API has a rate limit of 
<strong>
100 requests per day
</strong>
. Because of this, a meeting can only be updated for a maximum of 
<strong>
100 times within a 24-hour period
</strong>
. 
* The 
<code>
start_time
</code>
 value 
<strong>
must
</strong>
 be a future date. If the value is omitted or a date in the past, the API ignores this value and will 
<strong>
not
</strong>
 update any recurring meetings. 
* If the 
<code>
start_time
</code>
 value is a future date, the 
<code>
recurrence
</code>
 object is 
<strong>
required
</strong>
.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
meeting:write:admin
</code>
, 
<code>
meeting:write
</code>

</br>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
