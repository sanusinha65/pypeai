# Get `in-meeting` chat

GET {{baseUrl}}/meetings/{meetingId}/recordings


<h3>
Get 
<code>
in-meeting
</code>
 Chat
</h3>



<p>
After a meeting has ended and the recording files are finished processing, call the 
<a href="https://marketplace.zoom.us/docs/api-reference/zoom-api/cloud-recording/recordingget">
GET Meetings Recordings endpoint
</a>
.
</p>



<p>
In the payload you will see the file
<u>
type of 
<q>
CHAT
</q>
 which you can then download via the download
</u>
url.
</p>



<h5>

<strong>
Prerequisites
</strong>

</h5>



<ul>


<li>
  Ensure the meeting is recorded
</li>


<li>
  Ensure the 
<q>
Save chat messages from the meeting / webinar
</q>
 setting is enabled.
</li>


</ul>
