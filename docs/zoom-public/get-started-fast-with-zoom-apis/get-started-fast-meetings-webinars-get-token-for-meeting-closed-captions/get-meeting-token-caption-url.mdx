# Get meeting token (caption URL)

GET {{baseUrl}}/meetings/{meetingId}/token


<h3>
Get Meeting Token (Caption URL)
</h3>



<p>
As a meeting host, you can 
<a href="https://support.zoom.us/hc/en-us/articles/207279736">
add closed captions to Zoom meetings
</a>
 by providing the third-party closed captioning service with the caption URL. The caption URL allows the third-party service to stream text from their closed captioning software to the Zoom meeting. This article defines the format used by Zoom to receive Closed Caption data.
</p>



<p>
If you are new to using closed captioning with Zoom, please refer to our 
<a href="https://support.zoom.us/hc/en-us/articles/207279736">
closed captioning overview
</a>
.
</p>
