# Add a meeting registrant

POST {{baseUrl}}/meetings/{meetingId}/registrants


<h3>
Add a Meeting Registrant
</h3>



<p>
Use the 
<a href="https://support.zoom.us/hc/en-us/articles/211579443-Registration-for-Meetings">
Meeting Registration
</a>
 to generate unique join URLs for each participant. The unique join URLs (registration link) allow a user to join a meeting with their first/last name pre-set.
</p>
