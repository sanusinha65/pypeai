# Add a webinar registrant

POST {{baseUrl}}/webinars/{webinarId}/registrants


<h3>
Add a Webinar Registrant
</h3>



<p>
Use the 
<a href="https://support.zoom.us/hc/en-us/articles/204619915-Scheduling-a-webinar-with-registration">
Webinar Registration
</a>
 to generate unique join URLs for each participant. The unique join URLs (registration link) allow a user to join a meeting with their first/last name pre-set.
