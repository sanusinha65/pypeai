#Zoom Account API

Number of APIs: 50


<p>

<u>
Note: The Zoom Account API was formerly a subset of the Meeting API
</u>

</p>



<p>
The Zoom Account API lets developers access data related to Accounts, Dashboards, Information Barriers, and Roles. Use this API to build private services or public applications on the 
<a href="http://marketplace.zoom.us/">
Zoom App Marketplace
</a>
. Learn how to get your credentials and create private/public applications in our 
<a href="https://developers.zoom.us/docs/integrations/oauth/">
Authorization Guide
</a>
.
</p>



<p>
The API accepts 
<code>
application/json
</code>
 and 
<code>
multipart/form-data
</code>
, and responds with 
<code>
application/json
</code>
 and 
<code>
application/xml
</code>
. All endpoints are available at 
<code>
https://api.zoom.us/v2/
</code>
.
</p>
