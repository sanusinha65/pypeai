# Get locked settings

GET {{baseUrl}}/accounts/:accountId/lock_settings?option=&lt;string&gt;&amp;custom_query_fields=&lt;string&gt;


<p>
Retrieve an account&#39;s locked settings. 
</p>



<p>
Account admins and account owners can use 
<a href="https://support.zoom.us/hc/en-us/articles/115005269866">
Account Locked Settings
</a>
 to toggle settings on or off for all users in their account. 
</p>



<p>

<strong>
Note:
</strong>
 You can use Account Locked Settings with accounts that have master and sub accounts enabled.   
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or a higher paid account.   
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
account:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
MEDIUM
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `option` | string |  | Optional query parameters: 
* `meeting_security` &amp;mdash; Use this query parameter to view the meeting security settings applied to the user&#39;s account. |
| `custom_query_fields` | string |  | Provide the name of the field by which you would like to filter the response. For example, if you provide &amp;quot;host_video&amp;quot; as the value of this field, you will get a response similar to the following:  
 
{
    &amp;quot;schedule_meeting&amp;quot;: {
        &amp;quot;host_video&amp;quot;: false
    }
}
  
 You can provide multiple values by separating them with commas(example: &amp;quot;host_video,participant_video&amp;rdquo;). |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
