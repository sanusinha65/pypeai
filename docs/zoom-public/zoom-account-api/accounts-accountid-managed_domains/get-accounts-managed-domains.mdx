# Get account&#39;s managed domains

GET {{baseUrl}}/accounts/:accountId/managed_domains


<p>
Retrieve a list of an account&#39;s 
<a href="https://support.zoom.us/hc/en-us/articles/203395207">
managed domains
</a>
. To get the master account&#39;s managed domains, pass the 
<code>
me
</code>
 value for the 
<code>
accountId
</code>
 path parameter. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or a higher paid account with the Master account option enabled.
</p>
