# Update account settings

PATCH {{baseUrl}}/accounts/:accountId/settings?option=recording_authentication


<p>
Update an account&#39;s settings. 
To update the settings for a master account, pass the 
<code>
me
</code>
 value for the 
<code>
accountId
</code>
 path parameter. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* The account must be a paid account.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
account:write:admin
</code>

</p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>

<code>
MEDIUM
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `option` | string |  | Optional query parameters. 
* `meeting_authentication` - View the [meeting authentication settings](https://support.zoom.us/hc/en-us/articles/360037117472-Authentication-Profiles-for-Meetings-and-Webinars) applied to the user&#39;s account. 
* `recording_authentication` - View the [recording authentication settings](https://support.zoom.us/hc/en-us/articles/360037756671-Authentication-Profiles-for-Cloud-Recordings) applied to the user&#39;s account. 
* `security` - View the account&#39;s security settings. For example, passcode requirements for user login or two-factor authentication. 
* `meeting_security` - View the meeting security settings applied to the user&#39;s account. |
