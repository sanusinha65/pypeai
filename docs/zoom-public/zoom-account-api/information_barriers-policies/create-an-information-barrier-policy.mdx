# Create an Information Barrier policy

POST {{baseUrl}}/information_barriers/policies


<p>
Create a new Information Barrier policy. 
<a href="https://support.zoom.us/hc/en-us/articles/360040913711-Information-Barriers">
Information Barriers
</a>
 help customers control communication policies and meet regulatory requirements at scale. Use information barriers to prevent specific groups of users who possess sensitive information from communicating with others who should not know this information. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* 
<a href="https://support.zoom.us/hc/en-us/articles/201362003">
Contact Zoom Support
</a>
 to enable Information Barriers for your account.
</p>
