# List information Barrier policies

GET {{baseUrl}}/information_barriers/policies


<p>
Return a list of all 
<a href="https://support.zoom.us/hc/en-us/articles/360040913711-Information-Barriers">
Information Barriers
</a>
 policies and their information. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* 
<a href="https://support.zoom.us/hc/en-us/articles/201362003">
Contact Zoom Support
</a>
 to enable Information Barriers for your account.
</p>



<p>

<strong>
Scopes:

<code>
information_barriers:read:admin
</code>

</p>

MEDIUM
</code>
