# List Zoom meetings client feedback

GET {{baseUrl}}/metrics/client/feedback?from=&lt;date&gt;&amp;to=&lt;date&gt;


<p>
Use this API to return 
<a href="https://support.zoom.us/hc/en-us/articles/115005855266-End-of-Meeting-Feedback-Survey#h_e30d552b-6d8e-4e0a-a588-9ca8180c4dbf">
Zoom meetings client feedback
</a>
 survey results. You can specify a monthly date range for the Dashboard data using the 
<code>
from
</code>
 and 
<code>
to
</code>
 query parameters. The month should fall within the last six months. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or higher account. 
* The &quot;
<a href="https://support.zoom.us/hc/en-us/articles/115005838023">

<strong>
Feedback to Zoom
</strong>

</a>
&quot; option enabled.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
dashboard_home:read:admin
</code>
,
<code>
dashboard:read:admin
</code>

</p>

### Request Params
| Key | Datatype | Required | Description |
| `from` | string |  | (Required) Start date in &#39;yyyy-mm-dd&#39; format. The date range defined by the &amp;quot;from&amp;quot; and &amp;quot;to&amp;quot; parameters should only be one month as the report includes only one month worth of data at once. |
| `to` | string |  | (Required) End date. |
