# Get webinar details

GET {{baseUrl}}/metrics/webinars/:webinarId?type=live


<p>
Retrieve details from live or past webinars.  
</p>



<p>

<strong>
Prerequisites:
</strong>
  
</p>



<ul>


<li>
Business, Education or API Plan with Webinar add-on.
</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
dashboard_webinars:read:admin
</code>
,
<code>
dashboard:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Heavy
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `type` | string |  | The type of webinar to query: 
* `past` &amp;mdash; All past webinars. 
* `live` - All live webinars. 

This value defaults to `live`. |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
