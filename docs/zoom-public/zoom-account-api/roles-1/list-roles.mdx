# List roles

GET {{baseUrl}}/roles?type=common


<p>
List 
<a href="https://support.zoom.us/hc/en-us/articles/115001078646-Role-Based-Access-Control">
roles
</a>
 on your account
</p>



<p>

<strong>
Prerequisites
</strong>
 :
*  Pro or higher plan. 
*  For setting the initial role, you must be the Account Owner. 
*  For subsequent role management, you must be the Account Owner or user with role management permissions.
</p>

Scopes:

Medium

</p>



### Request Params
| Key | Datatype | Required | Description |
| `type` | string |  | Specify a value to get the response for the corresponding role type.  
    
 `common` - common roles of Zoom.  
 `iq` - roles of Zoom IQ Sales |
