# Update role information

PATCH {{baseUrl}}/roles/:roleId


<p>
Each Zoom user automatically has a 
<a href="https://support.zoom.us/hc/en-us/articles/115001078646-Role-Based-Access-Control">
role
</a>
 which can either be owner, administrator, or a member. Account Owners and users with edit privileges for Role management can add customized roles with a list.
</p>



<p>
Use this API to change the privileges, name and description of a specific role.  
</p>



<p>

<strong>
Pre-requisite:
</strong>
  
</p>



<ul>


<li>

<p>
A Pro or higher plan.  
</p>

</li>


<li>

<p>
For role management and updates, you must be the Account Owner or user with role management permissions.  
</p>

</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
role:write:admin
</code>

</p>

</p>
