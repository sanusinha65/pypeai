# Get invoice details

GET {{baseUrl}}/accounts/:accountId/billing/invoices/:invoiceId


<p>
Get detailed information about a specific 
<a href="https://support.zoom.us/hc/en-us/articles/207276556-Viewing-your-invoice-history#h_6710542f-23cc-4059-9cc7-ff02bec7314e">
invoice
</a>
.
<br>

 To retrieve a regular Zoom account&#39;s invoice details or a master account&#39;s invoice details, provide 
<code>
me
</code>
 as the value of 
<code>
accountId
</code>
 path parameter. To list a sub account&#39;s invoice details, provide the account ID of the sub account in the 
<code>
accountId
</code>
 path parameter. 
</p>



<p>

<strong>
Prerequisites:
</strong>

* Account must be enrolled in Pro or a higher plan.   
</p>



<p>

<strong>
Additional Rate Limit:
</strong>
 You can make 
<strong>
one
</strong>
 API request every 
<strong>
thirty
</strong>
 minutes until the daily limit is reached. This API has a daily limit of 
<strong>
100
</strong>
 requests per 
<strong>
account
</strong>
.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
billing:master
</code>

</p>
