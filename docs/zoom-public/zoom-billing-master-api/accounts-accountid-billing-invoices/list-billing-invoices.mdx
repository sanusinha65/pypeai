# List billing invoices

GET {{baseUrl}}/accounts/:accountId/billing/invoices?from=&lt;date&gt;&amp;to=&lt;date&gt;


<p>
List 
<a href="https://support.zoom.us/hc/en-us/articles/207276556-Viewing-your-invoice-history#h_6710542f-23cc-4059-9cc7-ff02bec7314e">
invoices
</a>
 of a Zoom account.
</p>



<p>
To list a regular Zoom account&#39;s invoices or a master account&#39;s invoices, provide 
<code>
me
</code>
 as the value of the 
<code>
accountId
</code>
 path parameter. To list a sub account&#39;s invoices, provide the account ID of the sub account in the 
<code>
accountId
</code>
 path parameter. 
</p>

Prerequisites:

### Request Params
| Key | Datatype | Required | Description |
| `from` | string |  | Start date for the invoice query in `yyyy-mm-dd` format. The date range defined by the &amp;ldquo;from&amp;rdquo; and &amp;ldquo;to&amp;rdquo; parameters should not exceed one year. The range defined should fall within the past three years.
 |
| `to` | string |  | End date for the invoice query in `yyyy-mm-dd` format |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
