# Get plan usage

GET {{baseUrl}}/accounts/:accountId/plans/usage


<p>
Get information on 
<a href="https://marketplace.zoom.us/docs/api-reference/other-references/plans">
plan usage
</a>
 for an account.  
</p>



<p>
This API supports standard and master accounts and subaccounts. 
</p>



<p>

<strong>
Prerequisite
</strong>
:   Account type: master account on a paid Pro, Business or Enterprise plan.   
</p>



<ul>


<li>

<p>
To get a standard account&#39;s plan usage, use the 
<code>
account:read:admin
</code>
 scope. Enter 
<code>
me
</code>
 as the value of the 
<code>
accountId
</code>
 path parameter. 
</p>

</li>


<li>

<p>
To get a master account&#39;s plan usage, use use the 
<code>
billing:master
</code>
 scope. Enter  
<code>
me
</code>
 as the value of the 
<code>
accountId
</code>
 path parameter. 
</p>

</li>


<li>

<p>
To get a subaccount&#39;s plan usage, use use the 
<code>
billing:master
</code>
 scope. Enter the subaccount&#39;s actual account ID as the value of the 
<code>
accountId
</code>
 path parameter. 
</p>

</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
billing:master
</code>
,
<code>
account:master
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
HEAVY
</code>

</p>
