# Get account plan information

GET {{baseUrl}}/accounts/:accountId/plans


<p>
Master accounts can retrieve its subaccounts&#39; plan information. 
</p>



<p>

<strong>
Prerequisite
</strong>
: This API can only be used by Master accounts that pay all billing charges of their associated Pro or higher sub accounts. 
</p>
