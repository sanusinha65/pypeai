# Subscribe account to a plan

POST {{baseUrl}}/accounts/:accountId/plans


<p>
Master accounts can subscribe a subaccount to a Zoom plan. 
</p>



<p>

<strong>
Prerequisite:
</strong>
 This API can only be used by Master accounts that pay all billing charges of their associated Pro or higher sub accounts.
  Zoom only allows 
<a href="https://developers.zoom.us/docs/api/rest/master-account-apis/">
approved partners
</a>
 to use Master APIs and manage sub accounts&#39; billing information. Email the partner programs team at 
<a href="mailto:partner-success@zoom.us">

<strong>
partner-success@zoom.us
</strong>

</a>
 for more details. 
</p>



<p>

<strong>
Note:
</strong>
 To subscribe to an add-on plan 
<strong>
after
</strong>
 subscribing to a base plan, you 
<strong>
must
</strong>
 use the 
<a href="/docs/api-reference/zoom-api/ma#operation/accountPlanAddonCreate">

<strong>
Subscribe account to an additional plan
</strong>

</a>
 API.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
billing:master
</code>

</p>
