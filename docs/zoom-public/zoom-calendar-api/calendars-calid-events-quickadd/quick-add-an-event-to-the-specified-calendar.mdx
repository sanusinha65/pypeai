# Quick add an event to the specified calendar

POST {{baseUrl}}/calendars/:calId/events/quickAdd?text=&lt;string&gt;&amp;sendUpdates=none


<p>
Creates an event based on a simple text string.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
calendar:write
</code>
,
<code>
calendar:write:admin
</code>

</p>

</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `text` | string |  | (Required) The text that describes the event to be created. |
| `sendUpdates` | string |  | The guests who should receive notifications about the creation of the new event. |
