# List the calendars in the user&#39;s own calendarList

GET {{baseUrl}}/calendars/users/:userIdentifier/calendarList?maxResults=&lt;integer&gt;&amp;minAccessRole=writer&amp;pageToken=&lt;string&gt;&amp;showDeleted=&lt;boolean&gt;&amp;showHidden=&lt;boolean&gt;


<p>
Returns the calendars in the user&#39;s calendar list.
</p>

### Request Params
| Key | Datatype | Required | Description |
| `maxResults` | string |  | The maximum number of entries returned on one result page. |
| `minAccessRole` | string |  | The minimum access role for the user in the returned entries. |
| `pageToken` | string |  | The token that specifies which result page to return. |
| `showDeleted` | string |  | Whether to include deleted calendar list entries in the result. |
| `showHidden` | string |  | Whether to show hidden entries. |
