# Create an address book unit

POST {{baseUrl}}/contact_center/address_books/units


<p>
Use this API to create an 
<a href="https://support.zoom.us/hc/en-us/articles/4471495629837-Managing-address-book-units">
address book unit
</a>
. Admins can use address book units to organize several 
<a href="https://support.zoom.us/hc/en-us/articles/4471544949389#:%7E:text=An%20address%20book%20is%20a%20collection%20of%20consumer%20information%20like%20display%20names%2C%20phone%20numbers%2C%20and%20locations.">
address books
</a>
. 
</p>



<p>

</p>
