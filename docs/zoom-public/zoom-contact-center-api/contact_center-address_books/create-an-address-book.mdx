# Create an address book

POST {{baseUrl}}/contact_center/address_books


<p>
Use this API to create an 
<a href="https://support.zoom.us/hc/en-us/articles/4471544949389">
address book
</a>
. An address book is a collection of consumer information like display names, phone numbers, and locations. 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
contact_center_contact:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
