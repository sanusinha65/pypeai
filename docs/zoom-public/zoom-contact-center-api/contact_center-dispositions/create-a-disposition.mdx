# Create a disposition

POST {{baseUrl}}/contact_center/dispositions


<p>
Create a new 
<a href="https://support.zoom.us/hc/en-us/articles/4470153057549-Managing-dispositions">
disposition
</a>
. Dispositions let agents assign an outcome or topic to each engagement. After creating dispositions, add them to queues. 
</p>



<p>

<strong>
Scopes:
</strong>

</p>
