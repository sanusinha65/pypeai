# Create a queue

POST {{baseUrl}}/contact_center/queues


<p>
Create an agent 
<a href="https://support.zoom.us/hc/en-us/articles/4423986595085">
queue
</a>
 to determine which agents calls are routed to. Queues also link to an existing routing profile to determine how calls are routed. 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
contact_center_queue:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>

</strong>

LIGHT
</code>

</p>
