# List recordings

GET {{baseUrl}}/contact_center/recordings?query_date_type=recording_start_time&amp;from=&lt;string&gt;&amp;to=&lt;string&gt;&amp;recording_type=automatic&amp;owner_type=user&amp;channel_type=voice&amp;next_page_token=&lt;string&gt;&amp;page_size=30


<p>
Return a list of available recordings. 
</p>

### Request Params
| Key | Datatype | Required | Description |
| `query_date_type` | string |  | Query date type. 
* `recording_start_time` &amp;mdash; The recording&#39;s start time 
* `recording_end_time` &amp;mdash; The recording&#39;s end time |
| `from` | string |  | The start time and date in ISO 8601 format: yyyy-MM-dd&#39;T&#39;HH:mm:ss&#39;Z&#39;, or yyyy-MM-dd&#39;T&#39;HH:mm:ss&#39;TZD&#39;. The defined date range should be a month, as the response only includes one month&#39;s worth of data. If unspecified, this parameter returns data from the past 30 days. |
| `to` | string |  | **Required** only when the `from` parameter is specified. The end time and date in ISO 8601 format: yyyy-MM-dd&#39;T&#39;HH:mm:ss&#39;Z&#39;, or yyyy-MM-dd&#39;T&#39;HH:mm:ss&#39;TZD&#39;, the same format as the `from` parameter. |
| `recording_type` | string |  | The recording&#39;s type. 
* `on_demand` &amp;mdash; Manually trigger recording 
* `automatic` &amp;mdash; Automatically trigger recording |
| `owner_type` | string |  | The recording&#39;s owner type. 
* `user` &amp;mdash; This recording belongs to a user 
* `queue` &amp;mdash; This recording belongs to a queue |
| `channel_type` | string |  | The recording&#39;s channel type. 
* `voice` &amp;mdash; Voice recording 
* `video` &amp;mdash; Video recording |
| `next_page_token` | string |  | Use the next page token to paginate through large result sets. A next page token returns whenever the set of available results exceeds the current page size. This token&#39;s expiration period is 15 minutes. |
| `page_size` | number |  | The number of items returned per page. |
