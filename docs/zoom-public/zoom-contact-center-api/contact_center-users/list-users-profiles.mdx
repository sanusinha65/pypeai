# List users&#39; profiles

GET {{baseUrl}}/contact_center/users?search_key=&lt;string&gt;&amp;next_page_token=&lt;string&gt;&amp;page_size=30&amp;region_id=&lt;string&gt;&amp;user_access=inactive


<p>
Returns a list of users and their information. 
</p>

### Request Params
| Key | Datatype | Required | Description |
| `search_key` | string |  | The user&#39;s email address or username. |
| `next_page_token` | string |  | Use the next page token to paginate through large result sets. A next page token is returned whenever the set of available results exceeds the current page size. This token&#39;s expiration period is 15 minutes. |
| `page_size` | number |  | The number of items returned per page. |
| `region_id` | string |  | The region&#39;s ID. |
| `user_access` | string |  | The user&#39;s access status. 
* `active` &amp;mdash; The user&#39;s role permissions allow them to access the Contact Center. 
* `inactive` &amp;mdash; The user cannot access the Contact Center. |
