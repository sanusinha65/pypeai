# List variables

GET {{baseUrl}}/contact_center/variables?variable_group_id=&lt;string&gt;&amp;data_type=currency&amp;variable_type=global_variable&amp;next_page_token=&lt;string&gt;&amp;page_size=30


<p>
Returns a list of variables for a specific variable group. 
</p>

| Key | Datatype | Required | Description |
| `variable_group_id` | string |  | (Required) The variable&#39;s group ID. |
| `data_type` | string |  | The data&#39;s type. 
* `string` 
* `number` 
* `boolean` 
* `date_time` 
* `currency` 
* `percentage` 
* `email` 
* `url` 
* `phone` - ([E.164 format](https://en.wikipedia.org/wiki/E.164)) |
| `variable_type` | string |  | The variable&#39;s type. 
* `global_variable` 
* `address_book_variable` |
| `next_page_token` | string |  | Use the next page token to paginate through large result sets. A next page token returns whenever the set of available results exceeds the current page size. This token&#39;s expiration period is 15 minutes. |
| `page_size` | number |  | The number of items returned per page. |
