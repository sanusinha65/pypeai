# Update a session

PATCH {{baseUrl}}/zoom_events/events/:eventId/sessions/:sessionId


<p>
Use this API to update an existing session in an event. This API is not allowed for single session event type.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
zoom_events_sessions:write:admin
</code>

<code>
zoom_events_sessions:write
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
LIGHT
</code>

</p>
