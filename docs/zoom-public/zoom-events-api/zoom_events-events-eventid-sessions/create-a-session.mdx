# Create a session

POST {{baseUrl}}/zoom_events/events/:eventId/sessions


<p>
Use this API to create a session. This API is not allowed for single session event type.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
zoom_events_sessions:write:admin
</code>

<code>
zoom_events_sessions:write
</code>

</p>

</code>
