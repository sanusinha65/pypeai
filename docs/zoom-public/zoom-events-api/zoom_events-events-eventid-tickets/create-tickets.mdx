# Create tickets

POST {{baseUrl}}/zoom_events/events/:eventId/tickets


<p>
Use this API to create tickets for an event. You can add a single ticket or up to 30 tickets in a batch operation.
 Please note that this request uses the 
<code>
pre-registration
</code>
 flow. 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
zoom_events_tickets:write
</code>

<code>
zoom_events_tickets:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
LIGHT
</code>

</p>
