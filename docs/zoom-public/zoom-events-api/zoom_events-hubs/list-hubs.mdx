# List hubs

GET {{baseUrl}}/zoom_events/hubs?role_type=host


<p>
Use this API to retrieve event hubs.
</p>

### Request Params
| Key | Datatype | Required | Description |
| `role_type` | string |  | (Required) The user role type:
* `host` &amp;mdash; All hosted Hubs.
* `attendee` &amp;mdash; All related Hubs. |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
