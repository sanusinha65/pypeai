#Zoom Mail API

Number of APIs: 45


<p>
he Zoom Mail API lets developers access information from Zoom. Use this API to build private services or public applications on the 
<a href="http://marketplace.zoom.us/">
Zoom App Marketplace
</a>
. Learn how to get your credentials and create private or public apps in our 
<a href="https://developers.zoom.us/docs/integrations/oauth/">
Authorization guide
</a>
. The API accepts 
<code>
application/json
</code>
 and 
<code>
multipart/form-data
</code>
, and 
<code>
responds with application/json
</code>
 and 
<code>
application/xml
</code>
. All endpoints are available at 
<code>
https://api.zoom.us/v2/
</code>
.
</p>



<p>
To use this API, you must have:
</p>



<ul>


<li>

<p>
Zoom One Pro or Standard Pro, Zoom One Business, or Zoom One Enterprise account
</p>

</li>


<li>

<p>
Account owner or admin privileges
</p>

</li>


</ul>



<p>

<strong>
Note
</strong>
: Pro accounts have the Zoom Mail Services enabled by default. For Business and Enterprise accounts, the Zoom Mail Services are disabled by default.
</p>
