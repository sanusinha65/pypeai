# List labels in the mailbox

GET {{baseUrl}}/emails/mailboxes/:email/labels?format=full


<p>
Lists all labels in the mailbox.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
mail:read
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
MEDIUM
</code>

</p>



<p>

<strong>
Not supported in Gov cluster
</strong>
 
</p>



### Request Params
| Key | Datatype | Required | Description |
| `format` | string |  | Enum value to control how much label information is returned. |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
