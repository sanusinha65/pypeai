# List emails from the mailbox

GET {{baseUrl}}/emails/mailboxes/:email/messages?maxResults=&lt;string&gt;&amp;pageToken=&lt;string&gt;&amp;labelIds=&lt;string&gt;&amp;q=&lt;string&gt;&amp;includeSpamTrash=&lt;boolean&gt;


<p>
Lists the messages in the user&#39;s mailbox.
</p>

### Request Params
| Key | Datatype | Required | Description |
| `maxResults` | string |  | Maximum number of messages to return. This field defaults to 50. The maximum allowed value for this field is 500. |
| `pageToken` | string |  | Page token to retrieve a specific page of results in the list. |
| `labelIds` | string |  | Only return messages with labels that match all of the specified label IDs in this query parameter. |
| `q` | string |  | Only return messages matching the specified elastic search query. |
| `includeSpamTrash` | string |  | Whether to include messages from SPAM and TRASH in the results. |
