# Grant a new delegate access on the mailbox

POST {{baseUrl}}/emails/mailboxes/:email/settings/delegates


<p>
Creates a delegate on the mailbox.  Managing delegate operations must be done by the mailbox owner.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>

</code>

</p>

</p>
