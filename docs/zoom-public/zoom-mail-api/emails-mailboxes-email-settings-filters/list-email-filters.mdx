# List email filters

GET {{baseUrl}}/emails/mailboxes/:email/settings/filters


<p>
Lists the message filters of a mailbox.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
mail:read
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
MEDIUM
</code>

</p>



<p>

<strong>
Not supported in Gov cluster
</strong>
