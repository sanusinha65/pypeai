#Zoom Marketplace API

Number of APIs: 6


<p>
The Zoom Marketplace APIs allow developers to access information from the Zoom platform. You can use this API to build private or public applications on the 
<a href="http://marketplace.zoom.us">
Zoom App Marketplace
</a>
. For more information about getting credentials and creating private or public applications, read our 
<a href="https://marketplace.zoom.us/docs/docs/guides/auth/oauth">
OAuth
</a>
 and 
<a href="https://marketplace.zoom.us/docs/guides/auth/jwt">
JWT
</a>
 documentation. Note: All endpoints are available via 
<code>
https
</code>
 and are located at 
<code>
api.zoom.us/v2/
</code>
.
</p>
