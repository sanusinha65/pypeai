# Add app allow requests for users

POST {{baseUrl}}/marketplace/apps/:appId/requests


<p>
Use this API to add app allow requests for all users, groups of users, or specific users. 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>

Light

</p>
