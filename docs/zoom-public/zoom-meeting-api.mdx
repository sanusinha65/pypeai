#Zoom Meeting API

Number of APIs: 172


<p>
The Zoom Meeting APIs let developers to access information from Zoom. You can use this API to build private services or public applications on the 
<a href="http://marketplace.zoom.us">
Zoom App Marketplace
</a>
. To learn how to get your credentials and create private/public applications, read our 
<a href="https://developers.zoom.us/docs/">
documentation
</a>
.
</p>



<p>
All endpoints are available via 
<code>
https
</code>
 and are located at 
<code>
api.zoom.us/v2/
</code>
.
</p>
