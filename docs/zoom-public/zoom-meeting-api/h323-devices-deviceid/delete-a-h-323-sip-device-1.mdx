# Delete a H.323/SIP device

DELETE {{baseUrl}}/h323/devices/:deviceId


<p>
A H.323 or SIP device can make a video call to a 
<a href="https://support.zoom.us/hc/en-us/articles/201363273-Getting-Started-With-H-323-SIP-Room-Connector">
Room Connector
</a>
 to join a Zoom cloud meeting. A Room Connector can also call out to a H.323 or SIP device to join a Zoom cloud meeting. Use this API to delete a H.323/SIP device from your Zoom account.  
</p>
