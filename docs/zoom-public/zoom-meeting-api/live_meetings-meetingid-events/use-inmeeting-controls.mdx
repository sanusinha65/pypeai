# Use in-meeting controls

PATCH {{baseUrl}}/live_meetings/:meetingId/events


<p>
Control 
<a href="https://support.zoom.us/hc/en-us/articles/360021921032-In-Meeting-Controls">
in-meeting
</a>
 features. In-meeting controls include starting and stopping a recording, pausing and resuming a recording, and inviting participants. 
</p>



<p>

<strong>
Note:
</strong>
 This API&#39;s recording control only works for cloud recordings. It does 
<strong>
not
</strong>
 work for local recordings. 
</p>



<p>

<strong>
Prerequisites:
</strong>

* The meeting 
<strong>
must
</strong>
 be a live meeting 
<strong>
except
</strong>
 inviting participants to the meeting through [call out (phone)/(room system)]. 
* Recording control: 
<a href="https://support.zoom.us/hc/en-us/articles/360060231472-Enabling-cloud-recording">
Cloud recording
</a>
 must be enabled on the account. 
* The user calling this API must be the host or an alternative meeting host.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
meeting:write
</code>
,
<code>
meeting:write:admin
</code>
,
<code>
meeting:master
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
