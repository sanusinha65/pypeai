# Delete a live webinar message

DELETE {{baseUrl}}/live_webinars/:webinarId/chat/messages/:messageId?file_ids=&lt;string&gt;


<p>
Deletes a message in a live webinar based on ID. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* Have Zoom enable the DLP for the in-meeting chat feature to use this API.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
webinar:write
</code>
,
<code>
webinar:write:admin
</code>

</p>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">

</code>

</p>
