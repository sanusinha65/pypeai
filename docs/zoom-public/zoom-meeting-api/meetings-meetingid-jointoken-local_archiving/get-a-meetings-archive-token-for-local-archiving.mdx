# Get a meeting&#39;s archive token for local archiving

GET {{baseUrl}}/meetings/:meetingId/jointoken/local_archiving


<p>
Get a meeting&#39;s archive token to allow local archiving. The archive token allows a meeting SDK app or bot to get archive permission to access the meeting&#39;s raw audio and video media stream in real-time. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher plan for the meeting host. 
* The 
<strong>
Archive meetings and webinars
</strong>
 account setting enabled in the Zoom web portal.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
meeting_token:read:admin:local_archiving
</code>

</p>
