# Get a meeting summary

GET {{baseUrl}}/meetings/:meetingId/meeting_summary


<p>
Displays information about a meeting summary.
</p>



<p>

<strong>
Prerequisites
</strong>
:
* Host user type must be Pro or higher plan.
* The Meeting Summary with AI Companion feature enabled in the host&#39;s account.
* E2ee meetings do not have summary feature enabled.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
meeting_summary:read:admin
</code>
,
<code>
meeting_summary:read
</code>

</p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>

LIGHT
</code>

</p>
