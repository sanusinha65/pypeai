# Get registration questions

GET {{baseUrl}}/meetings/:meetingId/recordings/registrants/questions


<p>
For 
<a href="https://support.zoom.us/hc/en-us/articles/360000488283-On-demand-Recordings">
on-demand
</a>
 meeting recordings, you can include fields with questions that will be shown to registrants when they register to view the recording.
</p>



<p>
Use this API to retrieve a list of questions that are displayed for users to complete when registering to view the recording of a specific meeting.  
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
recording:read:admin
</code>
,
<code>
recording:read
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">

</a>

</strong>

Light
</code>

</p>
