# Update registration questions

PATCH {{baseUrl}}/meetings/:meetingId/recordings/registrants/questions


<p>
For 
<a href="https://support.zoom.us/hc/en-us/articles/360000488283-On-demand-Recordings">
on-demand
</a>
 meeting recordings, you can include fields with questions that will be shown to registrants when they register to view the recording.
</p>



<p>
Use this API to update registration questions that are to be answered by users while registering to view a recording.  
</p>
