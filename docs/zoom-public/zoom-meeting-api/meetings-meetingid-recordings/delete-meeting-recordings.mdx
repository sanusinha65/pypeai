# Delete meeting recordings

DELETE {{baseUrl}}/meetings/:meetingId/recordings?action=trash


<p>
Delete all recording files of a meeting.  
</p>



<p>

<strong>
Prerequisites

### Request Params
| Key | Datatype | Required | Description |
| `action` | string |  | The recording delete actions:  
 `trash` - Move recording to trash.  
 `delete` - Delete recording permanently. |
