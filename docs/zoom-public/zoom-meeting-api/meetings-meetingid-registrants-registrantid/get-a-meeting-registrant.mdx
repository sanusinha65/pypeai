# Get a meeting registrant

GET {{baseUrl}}/meetings/:meetingId/registrants/:registrantId


<p>
Retrieve details on a specific user who has registered for the meeting. A host or a user with administrative permissions can require 
<a href="https://support.zoom.us/hc/en-us/articles/211579443-Registration-for-Meetings">
registration for Zoom meetings
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* The account must have a Meeting plan
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
meeting:read:admin
</code>
,
<code>
meeting:read
</code>

</p>

Rate Limit Label
</a>
