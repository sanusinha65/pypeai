# Add a meeting registrant

POST {{baseUrl}}/meetings/:meetingId/registrants?occurrence_ids=&lt;string&gt;


<p>
Create and submit a user&#39;s registration to a meeting. See 
<a href="https://support.zoom.us/hc/en-us/articles/202835649-Customizing-webinar-registration">
Customizing webinar registration
</a>
 for details on how to set the requirements for these fields. Note that there is a maximum limit of 4,999 registrants per meeting and users will see an error if the meeting&#39;s capacity is reached. 
</p>



<p>

<strong>
Prerequisites:

Licensed

 user type.
