# Get a meeting SIP URI with Passcode

POST {{baseUrl}}/meetings/:meetingId/sip_dialing


<p>
Get a meeting&#39;s SIP URI.  The URI consists of the meeting ID, (optional, user-supplied) passcode and participant identifier code.  The API return data also includes additional fields to indicate whether the API caller has a valid Cloud Room Connector subscription, the participant identifier code from the URI, and the SIP URI validity period (in seconds). 
</p>
