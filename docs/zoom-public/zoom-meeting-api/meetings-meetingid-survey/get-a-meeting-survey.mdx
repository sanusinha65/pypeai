# Get a meeting survey

GET {{baseUrl}}/meetings/:meetingId/survey


<p>
Display information about a 
<a href="https://support.zoom.us/hc/en-us/articles/4404969060621-Post-meeting-survey-and-reporting">
meeting survey
</a>
.  
<strong>
Prerequisites:
</strong>
 * The host has a 
<strong>
Pro
</strong>
 license. * The 
<a href="https://support.zoom.us/hc/en-us/articles/4404939095053-Enabling-meeting-surveys">

<strong>
Meeting Survey
</strong>

</a>
 feature is enabled on the host&#39;s account. * The meeting must be a scheduled meeting. Instant meetings do not have survey features enabled.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
meeting:read
</code>
,
<code>
meeting:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
LIGHT
</code>

</p>
