# Update a meeting

PATCH {{baseUrl}}/meetings/:meetingId?occurrence_id=&lt;string&gt;


<p>
Update meeting details.
</p>



<p>

<strong>
Note
</strong>
 
* The 
<code>
start_time
</code>
 value 
<strong>
must
</strong>
 be a future date. If the value is omitted or a date is in the past, the API ignores this value and does 
<strong>
not
</strong>
 update any recurring meetings. 
* The 
<code>
recurrence
</code>
 object is 
<strong>
required
</strong>
.
* This API has a rate limit of 
<strong>
100 requests per day
</strong>
. You can update a meeting for a maximum of 
<strong>
100 times within a 24-hour period
</strong>
. 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
meeting:write
</code>
,
<code>
meeting:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
LIGHT
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `occurrence_id` | string |  | Meeting occurrence ID. Support change of agenda, `start_time`, duration, or settings {`host_video`, `participant_video`, `join_before_host`, `mute_upon_entry`, `waiting_room`, `watermark`, `auto_recording`}. |
