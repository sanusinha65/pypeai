# Recover meeting recordings

PUT {{baseUrl}}/meetings/:meetingUUID/recordings/status


<p>
Zoom allows users to recover recordings from trash for up to 30 days from the deletion date. Use this API to recover all deleted 
<a href="https://support.zoom.us/hc/en-us/articles/203741855-Cloud-Recording">
Cloud Recordings
</a>
 of a specific meeting.  
</p>



<p>

<strong>
Prerequisites
</strong>
:
