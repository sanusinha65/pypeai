# List past meeting&#39;s poll results

GET {{baseUrl}}/past_meetings/:meetingId/polls


<p>

<a href="https://support.zoom.us/hc/en-us/articles/213756303-Polling-for-Meetings">
Polls
</a>

</p>

Prerequisites
