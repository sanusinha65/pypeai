# List webinar participants

GET {{baseUrl}}/past_webinars/:webinarId/participants?page_size=30&amp;next_page_token=&lt;string&gt;


<p>
Retrieve a list of all the participants who attended a webinar hosted in the past. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher plan with a webinar add-on.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
webinar:read:admin
</code>
,
<code>
webinar:read
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
MEDIUM
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `page_size` | number |  | The number of records returned within a single API call. |
| `next_page_token` | string |  | Use the next page token to paginate through large result sets. A next page token is returned whenever the set of available results exceeds the current page size. This token&#39;s expiration period is 15 minutes. |

| Key | Datatype | Required | Description |
