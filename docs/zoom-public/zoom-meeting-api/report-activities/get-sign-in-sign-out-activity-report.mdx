### Request Params
| Key | Datatype | Required | Description |
| `from` | string |  | Start date for which you would like to view the activity logs report. Using the `from` and `to` parameters, specify a monthly date range for the report as the API only provides one month worth of data in one request. The specified date range should fall within the last six months. |
| `to` | string |  | End date up to which you would like to view the activity logs report. |
| `page_size` | string |  | The number of records to be returned within a single API call |
| `next_page_token` | string |  | Next page token is used to paginate through large result sets |
