# Get billing invoice reports

GET {{baseUrl}}/report/billing/invoices?billing_id=&lt;string&gt;


<p>
Get department billing invoices reports for a specific billing period. Provide the 
<code>
billing_id
</code>
 of the billing period for which you would like to retrieve the invoices for. This ID can be retrieved from 
<strong>
Get Billing Reports
</strong>
 API. 
</p>



<p>

<strong>
Prerequisites:
</strong>
  
</p>



<ul>


<li>
Pro or a higher account with Department Billing option enabled. Contact the Zoom Support team to enable this feature.
</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
report:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Heavy
</code>

</p>

| Key | Datatype | Required | Description |

 |
