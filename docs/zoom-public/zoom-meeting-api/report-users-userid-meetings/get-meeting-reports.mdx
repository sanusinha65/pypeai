# Get meeting reports

GET {{baseUrl}}/report/users/:userId/meetings?from=&lt;date&gt;&amp;to=&lt;date&gt;&amp;page_size=30&amp;next_page_token=&lt;string&gt;&amp;type=past


<p>
Retrieve 
<a href="https://support.zoom.us/hc/en-us/articles/216378603-Meeting-Reporting">
report
</a>
 on past meetings and webinars for a specified time period. The time range for the report is limited to a month and the month must fall within the past six months.
</p>



<p>
Meetings and webinars are returned only if they have two or more unique participants.    
</p>

### Request Params
| Key | Datatype | Required | Description |
| `from` | string |  | (Required) Start date in &#39;yyyy-mm-dd&#39; format. The date range defined by the &amp;quot;from&amp;quot; and &amp;quot;to&amp;quot; parameters should only be one month as the report includes only one month worth of data at once. |
| `to` | string |  | (Required) End date. |
| `page_size` | number |  | The number of records returned within a single API call. |
| `next_page_token` | string |  | Use the next page token to paginate through large result sets. A next page token is returned whenever the set of available results exceeds the current page size. This token&#39;s expiration period is 15 minutes. |
| `type` | string |  | The meeting type to query for: 
* `past` &amp;mdash; All past meetings. 
* `pastOne` &amp;mdash; A single past user meeting. 
* `pastJoined` &amp;mdash; All past meetings the account&#39;s users hosted or joined. |
