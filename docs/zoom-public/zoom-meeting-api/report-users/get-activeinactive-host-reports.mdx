# Get active/inactive host reports

GET {{baseUrl}}/report/users?type=inactive&amp;from=&lt;date&gt;&amp;to=&lt;date&gt;&amp;page_size=30&amp;page_number=1&amp;next_page_token=&lt;string&gt;&amp;group_id=&lt;string&gt;


<p>
Retrieve a host report for a specified period of time within the last six months.
<br>

The report time range is limited to a month. 
</p>



<p>
You can specify the type of report and date range using the query parameters.  
</p>



<ul>


<li>

<p>
The 
<strong>
Active Hosts
</strong>
 report displays a list of meetings, participants, and meeting minutes.
An 
<strong>
active host
</strong>
 is defined as any user who has hosted at least one meeting during the during the month specified in the 
<code>
from
</code>
 and 
<code>
to
</code>
 range.
</p>

</li>


<li>

<p>
The 
<strong>
Inactive Hosts
</strong>
 report pulls a list of users who were not active during a specific period of time.
<br>

An 
<strong>
inactive host
</strong>
 is defined as any user who has not hosted any meetings during the specified period of time for the report. to be inactive.  
</p>

</li>


</ul>

### Request Params
| Key | Datatype | Required | Description |
| `type` | string |  | Active or inactive hosts.  
 `active` - Active hosts.   
 `inactive` - Inactive hosts. |
| `from` | string |  | (Required) Start date in &#39;yyyy-mm-dd&#39; format. The date range defined by the `from` and `to` parameters should only be one month as the report includes only one month worth of data at once. |
| `to` | string |  | (Required) End date. |
| `page_size` | number |  | The number of records returned within a single API call. |
| `page_number` | number |  | The page number of the current page in the returned records. |
| `next_page_token` | string |  | The next page token is used to paginate through large result sets. A next page token will be returned whenever the set of available results exceeds the current page size. The expiration period for this token is 15 minutes. |
| `group_id` | string |  | The group ID. To get a group ID, use the [**List groups**](/api-reference/zoom-api/methods#operation/groups) API. 

 **Note:** The API response will only contain users who are members of the queried group ID. |
