# Get webinar poll reports

GET {{baseUrl}}/report/webinars/:webinarId/polls


<p>
Retrieve a report on past 
<a href="https://support.zoom.us/hc/en-us/articles/203749865-Polling-for-Webinars">
webinar polls
</a>
