# List tracking fields

GET {{baseUrl}}/tracking_fields


<p>
Use this API to list all the 
<a href="https://support.zoom.us/hc/en-us/articles/115000293426-Scheduling-Tracking-Fields">
tracking fields
</a>
 on your Zoom account. Tracking fields let you analyze usage by various fields within an organization. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business, Education, API or higher plan.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
tracking_fields:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
