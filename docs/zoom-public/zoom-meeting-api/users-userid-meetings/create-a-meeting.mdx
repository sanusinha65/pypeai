# Create a meeting

POST {{baseUrl}}/users/:userId/meetings


<p>

<a href="https://support.zoom.us/hc/en-us/articles/201362413-Scheduling-meetings">
Create a meeting
</a>
 for a user. For user-level apps, pass 
<a href="https://developers.zoom.us/docs/api/rest/using-zoom-apis/#the-me-keyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<ul>


<li>
A meeting&#39;s 
<code>
start_url
</code>
 value is the URL a host or an alternative host can use to start a meeting. The expiration time for the 
<code>
start_url
</code>
 value is 
<strong>
two hours
</strong>
 for all regular users.
</li>


<li>
For 
<code>
custCreate
</code>
 meeting hosts (users created with the 
<code>
custCreate
</code>
 parameter via the 
<a href="https://developers.zoom.us/docs/api/rest/reference/zoom-api/methods/#operation/userCreate">

<strong>
Create users
</strong>

</a>
 API), the expiration time of the 
<code>
start_url
</code>
 parameter is 
<strong>
90 days
</strong>
 from the generation of the 
<code>
start_url
</code>
.
</li>


</ul>



<p>

<strong>
Note:
</strong>
 
</p>



<p>
For security reasons, the recommended way to programmatically get the updated 
<code>
start_url
</code>
 value after expiry is to call the 
<a href="/api-reference/zoom-api/methods#operation/meeting">

<strong>
Get a meeting
</strong>

</a>
 API. Refer to the 
<code>
start_url
</code>
 value in the response. 
</p>



<p>

<strong>
100 requests per day
</strong>
. The rate limit is applied against the 
<code>
userId
</code>
 of the 
<strong>
meeting host
</strong>
 used to make the request.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
meeting:write
</code>
,
<code>
meeting:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
MEDIUM
</code>

</p>
