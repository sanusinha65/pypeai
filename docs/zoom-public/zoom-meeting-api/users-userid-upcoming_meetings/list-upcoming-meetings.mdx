# List upcoming meetings

GET {{baseUrl}}/users/:userId/upcoming_meetings


<p>
List a Zoom user&#39;s upcoming meetings. For user-level apps, pass 
<a href="https://developers.zoom.us/docs/api/rest/using-zoom-apis/#the-me-keyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>

<strong>
Note
</strong>

* This API includes the meetings that Zoom users schedule and the meetings they are invited to join.
* This API 
<strong>
only
</strong>
 includes upcoming meetings within the next 24 hours.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
meeting:read
</code>
,
<code>
meeting:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
MEDIUM
</code>

</p>
