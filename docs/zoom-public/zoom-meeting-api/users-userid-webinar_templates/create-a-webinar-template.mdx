# Create a webinar template

POST {{baseUrl}}/users/:userId/webinar_templates


<p>
Use this API to create a webinar template from an existing webinar. 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
webinar:write:admin
</code>
,
<code>
webinar:write
</code>

</p>

<strong>

</p>
