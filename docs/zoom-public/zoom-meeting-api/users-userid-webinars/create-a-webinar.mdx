# Create a webinar

POST {{baseUrl}}/users/:userId/webinars


<p>
Schedule a webinar for a user who is a webinar host. For user-level apps, pass 
<a href="https://developers.zoom.us/docs/api/rest/using-zoom-apis/#the-me-keyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter. 
</p>



<p>
Webinars allow a host to broadcast a Zoom meeting to up to 10,000 attendees. 
</p>



<p>

<strong>
Rate limit:
</strong>

Up to a maximum of 
<strong>
100 requests per day
</strong>
. The rate limit is applied to the 
<code>
userId
</code>
 of the 
<strong>
webinar host
</strong>
 used to make the request. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher plan with a 
<a href="https://zoom.us/webinar">
Webinar plan
</a>
 add-on.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
webinar:write
</code>
,
<code>
webinar:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
LIGHT
</code>

</p>
