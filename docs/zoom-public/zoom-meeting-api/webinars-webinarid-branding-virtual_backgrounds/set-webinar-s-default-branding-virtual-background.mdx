### Request Params
| Key | Datatype | Required | Description |
| `id` | string |  | The Virtual Background file ID to update. |
| `set_default_for_all_panelists` | string |  | Whether to set the Virtual Background file as the new default for all panelists. This includes panelists not currently assigned a default Virtual Background. |
