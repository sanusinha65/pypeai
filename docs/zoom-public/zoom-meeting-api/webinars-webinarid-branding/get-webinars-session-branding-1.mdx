# Get webinar&#39;s session branding

GET {{baseUrl}}/webinars/:webinarId/branding


<p>
Use this API to get the webinar&#39;s 
<a href="https://support.zoom.us/hc/en-us/articles/4836268732045-Using-Webinar-Session-Branding">
Session Branding
</a>
 information. Session branding lets hosts visually customize a webinar by setting a webinar wallpaper that displays behind video tiles. Session branding also lets hosts set the Virtual Background for and apply name tags to hosts, alternative hosts, panelists, interpreters, and speakers. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher plan with the Webinar add-on. 
* The 
<strong>
Webinar Session Branding
</strong>
 setting enabled.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
webinar:read
</code>
,
<code>
webinar:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
