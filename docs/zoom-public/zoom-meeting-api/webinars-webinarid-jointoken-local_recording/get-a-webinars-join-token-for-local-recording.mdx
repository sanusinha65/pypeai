# Get a webinar&#39;s join token for local recording

GET {{baseUrl}}/webinars/:webinarId/jointoken/local_recording


<p>
Use this API to get a webinar&#39;s join token to allow for local recording. The join token lets a recording bot implemented using Zoom Meeting SDK to connect to a Zoom webinar. The recording bot can then automatically start locally recording. This supports both regular and raw local recording types. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher plan with a Webinar Add-on. 
* The 
<strong>
Local recording
</strong>
 user setting enabled in the Zoom web portal.
</p>
