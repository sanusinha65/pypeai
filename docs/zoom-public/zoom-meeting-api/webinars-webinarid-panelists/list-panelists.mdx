# List panelists

GET {{baseUrl}}/webinars/:webinarId/panelists


<p>
List all of a webinar&#39;s panelists.  
</p>



<p>
Webinar panelists can view and send video, screen share, annotate, and do much more compared to webinar attendees. 
</p>

Prerequisites:
