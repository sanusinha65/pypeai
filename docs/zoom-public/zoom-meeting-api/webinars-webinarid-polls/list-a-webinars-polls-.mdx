### Request Params
| Key | Datatype | Required | Description |
| `anonymous` | string |  | Whether to query for polls with the **Anonymous** option enabled: 
* `true` &amp;mdash; Query for polls with the **Anonymous** option enabled. 
* `false` &amp;mdash; Do not query for polls with the **Anonymous** option enabled. |
