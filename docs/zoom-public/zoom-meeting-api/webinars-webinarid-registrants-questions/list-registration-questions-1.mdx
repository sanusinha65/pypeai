# List registration questions

GET {{baseUrl}}/webinars/:webinarId/registrants/questions


<p>
List registration questions and fields that are to be answered by users while registering for a webinar. 
</p>



<p>
Scheduling a 
<a href="https://support.zoom.us/hc/en-us/articles/204619915-Scheduling-a-Webinar-with-Registration">
webinar with registration
</a>
 requires your registrants to complete a brief form with fields and questions before they can receive the link to join the webinar.  
</p>



<p>

<strong>
Prerequisites:
</strong>
  
</p>



<ul>


<li>
Pro or higher plan with the webinar add-on.
</li>


</ul>

<strong>
