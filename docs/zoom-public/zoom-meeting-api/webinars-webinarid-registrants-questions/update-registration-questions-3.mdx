# Update registration questions

PATCH {{baseUrl}}/webinars/:webinarId/registrants/questions


<p>
Update registration questions and fields of a scheduled webinar for users to answer during webinar registration. Scheduling a 
<a href="https://support.zoom.us/hc/en-us/articles/204619915-Scheduling-a-Webinar-with-Registration">
webinar with registration
</a>
 requires your registrants to complete a brief form with fields and questions before they can receive the link to join the webinar.  
</p>



<p>

<strong>
Prerequisites:
</strong>
  
</p>



<ul>


<li>
Pro or higher plan with a Webinar Add-on.
</li>


<li>
Registration option for Webinar should be set as required to use this API. 
</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
webinar:write
</code>
,
<code>
webinar:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
LIGHT
</code>

</p>
