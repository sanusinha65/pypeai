# Get a webinar survey

GET {{baseUrl}}/webinars/:webinarId/survey


<p>
Return information about a 
<a href="https://support.zoom.us/hc/en-us/articles/360048745651">
webinar survey
</a>
. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher plan with the Webinar add-on. 
* The 
<a href="https://support.zoom.us/hc/en-us/articles/360061293191-Enabling-webinar-survey">

<strong>
Webinar Survey
</strong>

</a>
 feature enabled in the host&#39;s account.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
webinar:read:admin
</code>
,
<code>
webinar:read
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
LIGHT
</code>

</p>
