# Update a webinar

PATCH {{baseUrl}}/webinars/:webinarId?occurrence_id=&lt;string&gt;


<p>
Make updates to a scheduled webinar. 
</p>



<p>

<strong>
100 requests per day
</strong>
. The rate limit is applied to the 
<code>
userId
</code>
 of the 
<strong>
webinar host
</strong>
 used to make the request. 
</p>



<p>

<strong>
Prerequisites
</strong>
 
* A Pro or higher plan with a webinar add-on.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
webinar:write
</code>
,
<code>
webinar:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
LIGHT
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `occurrence_id` | string |  | Webinar occurrence ID. Support change of agenda, start time, duration, and settings `host_video`, `panelist_video`, `hd_video, watermark`, `auto_recording`. |
