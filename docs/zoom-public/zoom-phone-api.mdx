#Zoom Phone API

Number of APIs: 536


<p>
You can access information from Zoom with Zoom Phone APIs to build private services or public applications on the 
<a href="https://marketplace.zoom.us/">
Zoom App Marketplace
</a>
.
</p>



<p>
To learn how to get your credentials and create private or public applications, see Zoom APIs use 
<a href="https://developers.zoom.us/docs/integrations/oauth/">
OAuth 2.0 authorization
</a>
.
</p>



<p>
All endpoints are available via 
<code>
https
</code>
 and are located at 
<code>
api.zoom.us/v2/
</code>
.
</p>



<p>
For instance, you can list all users on an account via 
<code>
https://api.zoom.us/v2/users/
</code>
.
</p>



<p>

<strong>
Note
</strong>
: You will get 
<code>
403
</code>
 response 
<code>
Zoom Phone has not been enabled for this account
</code>
 if the phone account is not set up.
</p>
