# Get Alert setting details

GET {{baseUrl}}/phone/alert_settings/:alertSettingId


<p>
Gets detailed information about a specific 
<a href="https://support.zoom.us/hc/en-us/articles/7146944434445">
Alert setting
</a>
.
</p>

<strong>
Prerequisites:
</strong>

</p>



<ul>


<li>
Pro or a higher account with Zoom Phone license 
</li>


<li>
Account owner or admin permissions
</li>


</ul>

<strong>
Scopes:

<code>
phone:read:admin
</code>
