# Get an audio item

GET {{baseUrl}}/phone/audios/:audioId


<p>
Use this API to get an audio item.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read
</code>
,
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Rate Limit Label:
</strong>
 
<code>
Light
</code>

</p>
