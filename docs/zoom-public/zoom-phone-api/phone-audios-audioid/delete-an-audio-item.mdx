# Delete an audio item

DELETE {{baseUrl}}/phone/audios/:audioId


<p>
Deletes an audio item. Only the admin or user can delete your audio.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business, or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write
</code>
,
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:delete:audio
</code>
,
<code>
phone:delete:audio:admin
</code>

</p>
