# Get an audio item

GET {{baseUrl}}/phone/audios/:audioId


<p>
Returns an audio item. Only the admin or user can access your audio.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read
</code>
,
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:audio
</code>
,
<code>
phone:read:audio:admin
</code>

</p>
