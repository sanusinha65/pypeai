# Update auto receptionist IVR

PATCH {{baseUrl}}/phone/auto_receptionists/:autoReceptionistId/ivr


<p>
Use this API to update the 
<a href="https://support.zoom.us/hc/en-us/articles/360038601971">
interactive voice response (IVR) system
</a>
 of the specified auto receptionist.
