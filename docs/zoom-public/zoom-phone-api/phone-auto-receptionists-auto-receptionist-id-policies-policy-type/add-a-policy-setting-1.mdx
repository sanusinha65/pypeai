# Add a policy setting

POST {{baseUrl}}/phone/auto_receptionists/:autoReceptionistId/policies/:policyType


<p>
Use this API to add a policy sub-setting according to the policy type for a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360021121312-Managing-Auto-Receptionists-and-Interactive-Voice-Response-IVR-">
auto receptionist
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or higher account plan with Zoom Phone License
* Account owner or admin permissions
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>

Light
</code>

</p>
