# Get an auto receptionist policy

GET {{baseUrl}}/phone/auto_receptionists/:autoReceptionistId/policies


<p>
Use this API to get the policy setting of a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360021121312-Managing-Auto-Receptionists-and-Interactive-Voice-Response-IVR-">
auto receptionist
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or a higher account with Zoom Phone license.
* Account owner or admin permissions.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
