# Update a policy setting

PATCH {{baseUrl}}/phone/auto_receptionists/:autoReceptionistId/policies/:policyType


<p>
Use this API to update the policy sub-setting of a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360021121312-Managing-Auto-Receptionists-and-Interactive-Voice-Response-IVR-">
auto receptionist
</a>
 according to the policy type. For example, you can update shared access members.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or higher account plan with Zoom Phone license
* Account owner or admin permissions
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:update:auto_receptionist_policy:admin
</code>

</p>

</a>

</p>
