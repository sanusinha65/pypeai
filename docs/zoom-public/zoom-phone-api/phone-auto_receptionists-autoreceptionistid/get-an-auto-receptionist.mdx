# Get an auto receptionist

GET {{baseUrl}}/phone/auto_receptionists/:autoReceptionistId


<p>
Use this API to get information on a specific auto receptionist.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or a higher account with Zoom Phone license.
* Account owner or admin permissions.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:auto_receptionist:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
