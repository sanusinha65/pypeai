# Add an auto receptionist

POST {{baseUrl}}/phone/auto_receptionists


<p>
Auto receptionists answer calls with a personalized recording and routes calls to a phone user, call queue, common area, voicemail or an IVR system. Use this API to add an 
<a href="https://support.zoom.us/hc/en-us/articles/360021121312-Managing-Auto-Receptionists-and-Interactive-Voice-Response-IVR-">
auto receptionist
</a>
 to a Zoom Phone
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or higher account with Zoom Phone license.
* Account owner or admin privileges 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:write:auto_receptionist:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
