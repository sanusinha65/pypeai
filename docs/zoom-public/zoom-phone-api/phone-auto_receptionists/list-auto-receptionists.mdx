# List auto receptionists

GET {{baseUrl}}/phone/auto_receptionists?page_size=30&amp;next_page_token=&lt;string&gt;


<p>
Use this API to list auto receptionists.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or a higher account with Zoom Phone license.
* Account owner or admin permissions.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:list_auto_receptionists:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `page_size` | number |  | The total number of records returned from a single API call. |
| `next_page_token` | string |  | The next page token paginates through a large set of results. A next page token is returned whenever the set of available results exceeds the current page size. The expiration period for this token is 15 minutes. |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
