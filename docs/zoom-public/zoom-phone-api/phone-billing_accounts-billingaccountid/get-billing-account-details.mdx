# Get billing account details

GET {{baseUrl}}/phone/billing_accounts/:billingAccountId


<p>
A Zoom account owner or a user with admin privilege can use this API to get information about a billing account.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or higher account plan with Zoom phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:billing_account:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
