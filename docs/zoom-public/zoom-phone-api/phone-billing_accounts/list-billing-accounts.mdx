# List billing accounts

GET {{baseUrl}}/phone/billing_accounts


<p>
A Zoom account owner or a user with admin privileges can use this API to retrieve a list of billing accounts.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or higher account plan with Zoom phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:list_billing_accounts:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
