# Delete a blocked list

DELETE {{baseUrl}}/phone/blocked_list/:accountBlockedId


<p>
A Zoom account owner or a user with admin privilege can block phone numbers for phone users in an account. Blocked numbers can be inbound (numbers will be blocked from calling in) and outbound (phone users in your account won&#39;t be able to dial those numbers).
</p>



<p>
Use this API to delete a blocked list and therefore removing the associated number from the blocked list. The number will be unblocked after the deletion.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or higher account plan with Zoom phone license
</p>
