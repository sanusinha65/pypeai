# Get call log details

GET {{baseUrl}}/phone/call_logs/:callLogId


<p>
Use this API to return information about a 
<a href="https://support.zoom.us/hc/en-us/articles/360021114452-Viewing-and-identifying-logs">
call log
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account 
* A Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read
</code>
, 
<code>
phone:read:admin
</code>
, 
<code>
phone_call_log:read
</code>
, 
<code>
phone_call_log:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits/#zoom-phone-apis">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
