# Get recording by call ID

GET {{baseUrl}}/phone/call_logs/:id/recordings


<p>
Use this API to get an account&#39;s call recording(
<a href="https://support.zoom.us/hc/en-us/articles/360038521091-Accessing-and-sharing-call-recordings">
https://support.zoom.us/hc/en-us/articles/360038521091-Accessing-and-sharing-call-recordings
</a>
) by the recording&#39;s 
<code>
callId
</code>
 or 
<code>
callLogId
</code>
 ID.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher account with Zoom Phone license. 
* Account owner or admin privileges
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>
, 
<code>
phone:write:admin
</code>

<br>


<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
