# Unassign a member

DELETE {{baseUrl}}/phone/call_queues/:callQueueId/members/:memberId


<p>
Use this API to remove a member who was previously added to a call queue. The member could be a phone user, 
<a href="https://support.zoom.us/hc/en-us/articles/360028516231-Managing-Common-Area-Phones">
common area phone
</a>
 or common area. Note that you cannot use this API to unassign a call queue manager.

Prerequisites:
