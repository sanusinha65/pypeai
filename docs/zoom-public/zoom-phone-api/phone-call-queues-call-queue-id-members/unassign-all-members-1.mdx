# Unassign all members

DELETE {{baseUrl}}/phone/call_queues/:callQueueId/members


<p>
Use this API to remove all members from a Call Queue who were previously assigned to that Call Queue. The members could be phone users or 
<a href="https://support.zoom.us/hc/en-us/articles/360028516231-Managing-Common-Area-Phones">
common area phones
</a>
.

Prerequisites:

</p>
