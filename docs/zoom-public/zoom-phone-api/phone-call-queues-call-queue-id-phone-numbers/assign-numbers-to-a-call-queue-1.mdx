# Assign numbers to a call queue

POST {{baseUrl}}/phone/call_queues/:callQueueId/phone_numbers


<p>
After 
<a href="https://support.zoom.us/hc/en-us/articles/360020808292#h_007ec8c2-0914-4265-8351-96ab23efa3ad">
buying phone number(s)
</a>
, you can assign it, allowing callers to directly dial a number to reach a 
<a href="https://support.zoom.us/hc/en-us/articles/360021524831-Managing-Call-Queues">
call queue
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>

</p>

</li>


<li>

</li>


<li>
Zoom Phone license
</li>


</ul>
