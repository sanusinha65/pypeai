# Change call queue manager

PUT {{baseUrl}}/phone/call_queues/:callQueueId/manager


<p>
A call queue manager has the privileges to manage the call queue&#39;s voicemail inbox and recordings, change all call queue settings and call queue policy settings.
</p>



<p>
Use this API to to set another phone user as the 
<a href="https://support.zoom.us/hc/en-us/articles/360021524831-Managing-Call-Queues#h_db06854b-e6a3-4afe-ba15-baf58f31f90c">
call queue manager
</a>
.
</p>
