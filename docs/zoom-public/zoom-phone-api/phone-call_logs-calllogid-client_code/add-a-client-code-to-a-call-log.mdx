# Add a client code to a call log

PUT {{baseUrl}}/phone/call_logs/:callLogId/client_code


<p>
Adds a client code to a 
<a href="https://support.zoom.us/hc/en-us/articles/360040999352-Assigning-client-codes-to-phone-calls">
call log
</a>
. You can track call logs with a client code. 
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business, or Education account
* Zoom Phone license 
</p>

<strong>
Scopes:

phone:write:admin
</code>

</p>
