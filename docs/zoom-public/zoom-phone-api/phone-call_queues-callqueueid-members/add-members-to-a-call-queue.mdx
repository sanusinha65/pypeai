# Add members to a call queue

POST {{baseUrl}}/phone/call_queues/:callQueueId/members


<p>
Add phone users and/or 
<a href="https://support.zoom.us/hc/articles/4481136653709">
common areas
</a>
 as members to a specific call queue.
</p>

<strong>
Prerequisites:
