# Unassign all members

DELETE {{baseUrl}}/phone/call_queues/:callQueueId/members


<p>
Removes all members from a call queue who were previously assigned to that call queue. The members could be phone users or 
<a href="https://support.zoom.us/hc/articles/4481136653709">
common areas
</a>
.
</p>
