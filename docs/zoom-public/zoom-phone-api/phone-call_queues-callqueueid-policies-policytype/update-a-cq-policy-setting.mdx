# Update a CQ policy setting

PATCH {{baseUrl}}/phone/call_queues/:callQueueId/policies/:policyType


<p>
Use this API to update the policy sub-setting for a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360021524831">
call queue
</a>
 according to the 
<code>
policyType
</code>
. For example, you can use this API to update shared access members.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* Pro or higher account with Zoom Phone license.
* Account owner or admin privileges 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:update:call_queue_policy:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
