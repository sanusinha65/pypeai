# Create a call queue

POST {{baseUrl}}/phone/call_queues


<p>

<a href="https://support.zoom.us/hc/en-us/articles/360021524831-Managing-Call-Queues#h_e81faeeb-9184-429a-aaea-df49ff5ff413">
Creates a call queue
</a>
. Call queues allow you to route incoming calls to a group of users. For instance, you can use call queues to route calls to various departments in your organization such as sales, engineering, billing, customer service, and so on.
 You can add phone users or common areas to call queues.
</p>
