# List calling plans

GET {{baseUrl}}/phone/calling_plans


<p>
Use this API to return all of an account&#39;s Zoom Phone 
<a href="https://marketplace.zoom.us/docs/api-reference/other-references/plans#zoom-phone-calling-plans">
calling plans
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or a higher account 
* A Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:list_calling_plans:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
