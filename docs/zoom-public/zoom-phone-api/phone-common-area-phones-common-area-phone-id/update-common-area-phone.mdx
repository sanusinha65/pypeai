# Update common area phone

PATCH {{baseUrl}}/phone/common_area_phones/:commonAreaPhoneId


<p>
Use this API to update details on a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360028516231-Managing-Common-Area-Phones">
common area phone
</a>
 in an account.
</p>



<p>
A common area phone can be provisioned by a Zoom account owner or a Zoom admin so that anyone in an organization can use it. For example, if your office has shared desks that don&#39;t belong to a specific employees, you could add a common area phone so that any person can use it.
</p>



<p>

</code>

</p>

Prerequisites:

</p>
