# Add common area settings

POST {{baseUrl}}/phone/common_areas/:commonAreaId/settings/:settingType


<p>
Use this API to add the common area setting according to the setting type, specifically for desk phones.
</p>



<p>

<strong>
Note
</strong>
: For use by customers who opted for 
<code>
Common Area Optimization
</code>
  
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or a higher account with Zoom Phone license.
* Account owner or admin permissions.
</p>



<p>

<strong>
Scope:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
