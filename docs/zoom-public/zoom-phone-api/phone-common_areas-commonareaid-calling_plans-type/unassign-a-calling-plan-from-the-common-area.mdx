# Unassign a calling plan from the common area

DELETE {{baseUrl}}/phone/common_areas/:commonAreaId/calling_plans/:type?billing_account_id=&lt;string&gt;


<p>
Use this API to unassign a calling plan from the common area.
</p>



<p>

<strong>
Note
</strong>

<code>
Common Area Optimization

</p>
