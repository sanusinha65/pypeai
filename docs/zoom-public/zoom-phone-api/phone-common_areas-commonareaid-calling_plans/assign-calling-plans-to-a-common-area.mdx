# Assign calling plans to a common area

POST {{baseUrl}}/phone/common_areas/:commonAreaId/calling_plans


<p>
Use this API to assign calling plans to a common area.
</p>



<p>

<strong>
Note
</strong>
: For use by customers who opted for 
<code>
Common Area Optimization
</code>
  
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or a higher account with Zoom Phone license.
* Account owner or admin permissions.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:write:common_area_calling_plan:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
