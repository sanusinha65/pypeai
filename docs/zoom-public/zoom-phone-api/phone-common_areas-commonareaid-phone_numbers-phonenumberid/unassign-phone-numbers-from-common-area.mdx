# Unassign phone numbers from common area

DELETE {{baseUrl}}/phone/common_areas/:commonAreaId/phone_numbers/:phoneNumberId


<p>
Use this API to unassign a phone number from a common area.
</p>



<p>

<strong>
Note
</strong>
: For use by customers who opted for 
<code>
Common Area Optimization
</code>
  
</p>



<p>

<strong>
Prerequisites:
</strong>

* A Pro or a higher account with a Zoom Phone license
* An account owner or admin permissions
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:

<code>

</code>

</p>
