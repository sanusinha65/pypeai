# List common areas

GET {{baseUrl}}/phone/common_areas?page_size=30&amp;next_page_token=&lt;string&gt;


<p>
Lists common areas under an account.
</p>

<strong>
Note
</strong>
: For use by customers who opted for 
<code>
Common Area Optimization
</code>

</li>

Account owner or admin permissions
