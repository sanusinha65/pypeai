# Delete a device

DELETE {{baseUrl}}/phone/devices/:deviceId


<p>
Remove a 
<a href="https://support.zoom.us/hc/en-us/articles/360021119092">
desk phone device or ATA (Analog Telephone Adapter)
</a>
 from the Zoom Phone System Management.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or a higher account with Zoom Phone license
* Account owner or admin permissions
* Device must not have been assigned to a user.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>

Light
</code>

</p>
