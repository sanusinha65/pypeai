# Get device details

GET {{baseUrl}}/phone/devices/:deviceId


<p>
Gets detailed information about a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360021119092">
desk phone device
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Pro or a higher account with Zoom Phone license
* Account owner or admin permissions
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:device:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
