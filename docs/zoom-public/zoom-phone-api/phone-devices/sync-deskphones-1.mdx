# Sync deskphones

POST {{baseUrl}}/phone/devices/sync


<p>
Use this API to resync all online zero-touch or assisted-provisioning devices in an account or a site. Only allows sending one request every 15 minutes.
</p>



<p>

<strong>
Prerequisites:
</strong>

</p>



<ul>


<li>
Pro or a higher account with Zoom Phone license
</li>


<li>
Account owner or admin permissions

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</li>


</ul>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Heavy
</code>

</p>
