# Assign phone numbers to the emergency number pool

POST {{baseUrl}}/phone/emergency_number_pools/phone_numbers


<p>
Use this API to assign phone numbers to the 
<a href="https://support.zoom.us/hc/en-us/articles/360062110192-Routing-emergency-calls">
Emergency Number Pool
</a>
.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write
</code>
, 
<code>
phone:write:admin
</code>

<br>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account 
* A Zoom Phone license
</p>
