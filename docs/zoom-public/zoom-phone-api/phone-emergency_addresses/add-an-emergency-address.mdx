# Add an emergency address

POST {{baseUrl}}/phone/emergency_addresses


<p>
Adds an emergency address. If the address provided is not an exact match, the system generated corrected address will be used. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* Pro or a higher account with Zoom Phone license 
* Account owner or admin permissions
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:write:emergency_address:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
