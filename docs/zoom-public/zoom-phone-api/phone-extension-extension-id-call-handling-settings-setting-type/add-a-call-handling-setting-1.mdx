# Add a call handling setting

POST {{baseUrl}}/phone/extension/:extensionId/call_handling/settings/:settingType


<p>
Use this API to create a Zoom Phone call handling setting. Call handling settings let you control how your system routes calls during business, closed, or holiday hours. For more information, read our 
<a href="https://support.zoom.us/hc/en-us/articles/360059966372-Customizing-call-handling-settings">
Customizing call handling settings
</a>
 documentation.
</p>



<p>

<strong>
Applicable to user, call queue, or auto receptionist call handling at this time.
</strong>
 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

Rate Limit Label

Light
</code>

</p>



<p>

<strong>
Prerequisites:

</p>
