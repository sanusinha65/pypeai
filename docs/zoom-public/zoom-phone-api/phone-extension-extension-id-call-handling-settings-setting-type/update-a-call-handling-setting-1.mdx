# Update a call handling setting

PATCH {{baseUrl}}/phone/extension/:extensionId/call_handling/settings/:settingType


<p>
Use this API to update a Zoom Phone&#39;s call handling setting. For more information, read our 
<a href="https://support.zoom.us/hc/en-us/articles/360059966372-Customizing-call-handling-settings">
Customizing call handling settings
</a>
 documentation.
</p>



<p>

<strong>
Applicable to user, call queue, or auto receptionist call handling at this time.
</strong>
 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

<br>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>
 
* Pro or a higher account with Zoom Phone enabled
</p>
