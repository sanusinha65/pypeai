# Update a call handling setting

PATCH {{baseUrl}}/phone/extension/:extensionId/call_handling/settings/:settingType


<p>
Updates a Zoom Phone&#39;s call handling setting. 
</p>



<p>
Call handling settings allow you to control how your system routes calls during business, closed, or holiday hours. For more information, read our 
<a href="https://developers.zoom.us/docs/zoom-phone/call-handling/">
Call Handling API guide
</a>
 or Zoom support article 
<a href="https://support.zoom.us/hc/en-us/articles/360059966372-Customizing-call-handling-settings">
Customizing call handling settings
</a>
.
</p>



<p>

<strong>
Applicable to user, call queue, auto receptionist, or shared line group call handling at this time.
</strong>
 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* Pro or a higher account with Zoom Phone enabled
</p>

<strong>
Scopes:

<code>

</code>

</p>



<p>

<strong>
Granular Scopes:

</code>

</p>
