# Get call handling settings

GET {{baseUrl}}/phone/extension/:extensionId/call_handling/settings


<p>
Returns information about a Zoom Phone&#39;s call handling settings. Call handling settings let you control how your system routes calls during business, closed, or holiday hours. For more information, read our 
<a href="https://developers.zoom.us/docs/zoom-phone/call-handling/">
API guide
</a>
 or Zoom support article 
<a href="https://support.zoom.us/hc/en-us/articles/360059966372-Customizing-call-handling-settings">
Customizing call handling settings
</a>
.
<strong>
Applicable to user, call queue, auto receptionist, or shared line group call handling at this time.
</strong>
 
<strong>
Prerequisites:
</strong>
 * Pro or a higher account with Zoom Phone enabled
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</code>
