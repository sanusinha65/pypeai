# Get line key position and settings information

GET {{baseUrl}}/phone/extension/:extensionId/line_keys


<p>
Use this API to get the Zoom Phone 
<a href="https://support.zoom.us/hc/en-us/articles/360040587552">
line key settings
</a>
 information.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account 
* A Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>
,
<code>
phone:read
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:line_keys
</code>
,
<code>
phone:read:line_keys:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
