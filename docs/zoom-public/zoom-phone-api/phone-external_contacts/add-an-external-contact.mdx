# Add an external contact

POST {{baseUrl}}/phone/external_contacts


<p>
Adds an external contact.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* Pro or a higher account with Zoom Phone license 
* Account owner or admin permissions
</p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
