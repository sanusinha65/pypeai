# List external contacts

GET {{baseUrl}}/phone/external_contacts?next_page_token=&lt;string&gt;&amp;page_size=30


<p>
Lists the external contacts.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* Pro or a higher account with Zoom Phone license 
* Account owner or admin permissions
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:list_external_contacts:admin
</code>

</p>



<p>

<strong>

Rate Limit Label
</a>
:
</strong>

</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `next_page_token` | string |  | The next page token paginates through a large set of results. A next page token is returned whenever the set of available results exceeds the current page size. The expiration period for this token is 15 minutes. |
| `page_size` | number |  | The number of records returned within a single API call. |
