# Get firmware update rule information

GET {{baseUrl}}/phone/firmware_update_rules/:ruleId


<p>
Use this API to get the 
<a href="https://support.zoom.us/hc/en-us/articles/360054198852-Setting-up-firmware-update-rules">
firmware update rule
</a>
 information.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>

<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Rate Limit Label:
</strong>
 
<code>
Light
</code>

</p>






### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
