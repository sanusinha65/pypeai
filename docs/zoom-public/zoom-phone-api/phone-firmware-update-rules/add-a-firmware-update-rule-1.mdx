# Add a firmware update rule

POST {{baseUrl}}/phone/firmware_update_rules


<p>
Use this API to add a 
<a href="https://support.zoom.us/hc/en-us/articles/360054198852-Setting-up-firmware-update-rules">
firmware update rule
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business, or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>

<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Rate Limit Label:
</strong>
 
<code>
Light
</code>

</p>
