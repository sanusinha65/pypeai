# Delete firmware update rule

DELETE {{baseUrl}}/phone/firmware_update_rules/:ruleId?restart_type=1

Use this API to delete the 
<a href="https://support.zoom.us/hc/en-us/articles/360054198852-Setting-up-firmware-update-rules">
firmware update rule
</a>
.
</p>
