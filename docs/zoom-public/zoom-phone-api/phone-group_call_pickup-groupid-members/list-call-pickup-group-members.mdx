# List call pickup group members

GET {{baseUrl}}/phone/group_call_pickup/:groupId/members?page_size=30&amp;next_page_token=&lt;string&gt;&amp;site_id=&lt;string&gt;&amp;extension_type=commonArea


<p>
Use this API to retrieve members of a 
<a href="https://support.zoom.us/hc/en-us/articles/360060107472-Setting-up-and-using-group-call-pickup">
call pickup group
</a>
 in an account.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher account plan 
* A Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:call_pickup_group_member:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `page_size` | number |  | The number of records returned within a single API call. |
| `next_page_token` | string |  | The next page token paginates through a large set of results. A next page token is returned whenever the set of available results exceeds the current page size. The expiration period for this token is 15 minutes. |
| `site_id` | string |  | Unique identifier of the site. |
| `extension_type` | string |  | Type of the assignee. |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
