# Get call pickup group by ID

GET {{baseUrl}}/phone/group_call_pickup/:groupId


<p>
Use this API to retrieve information on a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360060107472-Setting-up-and-using-group-call-pickup">
Group Call Pickup
</a>
 object in an account. 
</p>



<p>

<strong>
Prerequisites:

* A Pro or higher account plan 
* A Zoom Phone license

<strong>
Scopes:

phone:read:admin

</p>
