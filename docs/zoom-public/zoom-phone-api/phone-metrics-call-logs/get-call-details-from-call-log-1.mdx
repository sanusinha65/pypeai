# Get call details from call log

GET {{baseUrl}}/phone/metrics/call_logs/:call_id


<p>
Call logs provide a record of all incoming and outgoing calls over Zoom Phone in an account. 
</p>



<p>
Use this API to list call log details of a specific call. 
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business, or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>
, 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Rate Limit Label:
</strong>
 
<code>
Light
</code>

</p>
