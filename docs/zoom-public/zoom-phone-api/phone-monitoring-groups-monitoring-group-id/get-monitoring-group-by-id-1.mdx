# Get monitoring group by ID

GET {{baseUrl}}/phone/monitoring_groups/:monitoringGroupId


<p>
Use this API to return a 
<a href="https://support.zoom.us/hc/en-us/articles/360044804711">
Monitoring Group
</a>
 for the specified ID.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

<br>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>

 * A Business or Enterprise account 
* A Zoom Phone license
</p>
