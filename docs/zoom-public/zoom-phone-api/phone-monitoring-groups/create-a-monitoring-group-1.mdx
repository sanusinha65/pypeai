# Create a monitoring group

POST {{baseUrl}}/phone/monitoring_groups


<p>
Use this API to create a 
<a href="https://support.zoom.us/hc/en-us/articles/360044804711">
Monitoring Group
</a>
.
</p>

<strong>
Scopes:
</strong>
 
<code>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">

Light
