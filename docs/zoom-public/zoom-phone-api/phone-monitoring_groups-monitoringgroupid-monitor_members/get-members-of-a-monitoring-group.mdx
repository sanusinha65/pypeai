# Get members of a monitoring group

GET {{baseUrl}}/phone/monitoring_groups/:monitoringGroupId/monitor_members?member_type=monitor&amp;page_size=&lt;integer&gt;&amp;next_page_token=&lt;string&gt;


<p>
Use this API to return members list of a 
<a href="https://support.zoom.us/hc/en-us/articles/360044804711">
Monitoring Group
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>

 * A Business or Enterprise account 
* A Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>

</code>

</p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>

</strong>

Medium
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `member_type` | string |  | (Required) Member type |
| `page_size` | string |  | The size of the page. |
| `next_page_token` | string |  | The current page number of returned records. |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
