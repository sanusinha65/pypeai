# Get a list of monitoring groups on an account

GET {{baseUrl}}/phone/monitoring_groups?type=2&amp;site_id=&lt;string&gt;&amp;page_size=&lt;integer&gt;&amp;next_page_token=&lt;string&gt;


<p>
Returns an account&#39;s 
<a href="https://support.zoom.us/hc/en-us/articles/360044804711">
monitoring group
</a>
 list.
</p>



<p>

<strong>
Prerequisites:
</strong>

 * A Business or Enterprise account 
* A Zoom Phone license

### Request Params
| Key | Datatype | Required | Description |
| `type` | number |  | The monitoring group&#39;s type. |
| `site_id` | string |  | The unique identifier of the monitoring group&#39;s site. |
| `page_size` | string |  | The size of the page. |
| `next_page_token` | string |  | The current page number of returned records. |
