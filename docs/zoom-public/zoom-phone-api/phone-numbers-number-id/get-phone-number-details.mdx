# Get phone number details

GET {{baseUrl}}/phone/numbers/:numberId


<p>
Use this API to get information about an account&#39;s Zoom Phone number.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

<br>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher account plan 
* A Zoom phone license
</p>
