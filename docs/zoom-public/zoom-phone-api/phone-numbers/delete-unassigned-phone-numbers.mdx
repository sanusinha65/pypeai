# Delete unassigned phone numbers

DELETE {{baseUrl}}/phone/numbers?phone_numbers=&lt;string&gt;&amp;phone_numbers=&lt;string&gt;


<p>
Deletes unassigned 
<a href="https://support.zoom.us/hc/en-us/articles/360020808292-Managing-Phone-Numbers#h_38ba8b01-26e3-4b1b-a9b5-0717c00a7ca6">
phone numbers
</a>
. Up to 20 phone numbers can be removed in a single request.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account 
* A Zoom Phone license 
* The user must have been previously assigned a Zoom Phone number
</p>

<strong>

phone:write:admin
</code>

</p>

</p>
