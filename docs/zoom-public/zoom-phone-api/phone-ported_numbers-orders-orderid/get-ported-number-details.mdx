# Get ported number details

GET {{baseUrl}}/phone/ported_numbers/orders/:orderId


<p>
Use this API to get details on the ported numbers by specifying 
<code>
order_id
</code>
.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher account plan 
* A Zoom phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>
,
<code>
phone_peering:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>

</code>

</p>
