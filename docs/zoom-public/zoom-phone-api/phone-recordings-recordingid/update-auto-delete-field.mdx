# Update auto delete field

PATCH {{baseUrl}}/phone/recordings/:recordingId


<p>
Updates the auto delete field for recording. It only updates if you enable the 
<strong>
Auto Delete Data After Retention Duration
</strong>
 setting in the account settings for recordings. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* User must belong to a Business or Enterprise account 
* User must have a Zoom Phone license.
</p>
