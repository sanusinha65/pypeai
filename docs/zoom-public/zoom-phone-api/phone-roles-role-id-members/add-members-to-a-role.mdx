# Add members to a role

POST {{baseUrl}}/phone/roles/:roleId/members


<p>
Use this API to add member(s) to a role.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business, or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>

<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Rate Limit Label:
</strong>
 
<code>
Light
</code>

</p>
