# Update a phone role

PATCH {{baseUrl}}/phone/roles/:roleId


<p>
Use this API to update a role.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business, or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>

<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Rate Limit Label:
</strong>
 
<code>
Light
</code>

</p>

```
{&quot;name&quot;=&gt;&quot;Phone Super Admin&quot;, &quot;description&quot;=&gt;&quot;Admin has full privileges to access and manage the Zoom Phone (default).&quot;}
```
