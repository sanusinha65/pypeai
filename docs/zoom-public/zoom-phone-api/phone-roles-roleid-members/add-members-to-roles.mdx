# Add members to roles

POST {{baseUrl}}/phone/roles/:roleId/members


<p>

<a href="https://support.zoom.us/hc/en-us/articles/360042099012-Using-Zoom-Phone-role-management#h_01EFHY1R4QWAYTA6Z661NM9Q27">
roles
</a>
.
</p>



<p>

<strong>
