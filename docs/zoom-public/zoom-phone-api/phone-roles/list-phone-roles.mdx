# List phone roles

GET {{baseUrl}}/phone/roles


<p>
Use this API to get phone roles.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>

<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Rate Limit Label:
</strong>
 
<code>
Medium
</code>

</p>

| `Accept` | string |  |  |
