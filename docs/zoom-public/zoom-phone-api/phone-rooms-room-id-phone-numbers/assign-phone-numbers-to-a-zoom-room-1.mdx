# Assign phone numbers to a Zoom Room

POST {{baseUrl}}/phone/rooms/:roomId/phone_numbers


<p>
Use this API to 
<a href="https://support.zoom.us/hc/en-us/articles/360025153711">
assign phone numbers to a Zoom Room
</a>
. Up to 200 numbers at a time.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account 
* A Zoom Phone license
</p>
