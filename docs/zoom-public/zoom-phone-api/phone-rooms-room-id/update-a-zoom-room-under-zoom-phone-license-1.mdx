# Update a Zoom Room under Zoom Phone license

PATCH {{baseUrl}}/phone/rooms/:roomId


<p>
Use this API to update a 
<a href="https://support.zoom.us/hc/en-us/articles/360025153711">
Zoom Room
</a>
 under the account that has the Zoom Phone license assigned.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher account plan 
* A Zoom Phone license
</p>
