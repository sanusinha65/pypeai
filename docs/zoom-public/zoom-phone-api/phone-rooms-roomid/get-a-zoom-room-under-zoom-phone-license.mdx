# Get a Zoom Room under Zoom Phone license

GET {{baseUrl}}/phone/rooms/:roomId


<p>
Use this API to get a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360025153711">
Zoom Room
</a>
 in an account that has the Zoom Phone license assigned.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or higher account plan 
* A Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:room:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
