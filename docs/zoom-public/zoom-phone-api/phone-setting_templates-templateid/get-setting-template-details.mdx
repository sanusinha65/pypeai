# Get setting template details

GET {{baseUrl}}/phone/setting_templates/:templateId?custom_query_fields=&lt;string&gt;


<p>
Returns information about an account&#39;s phone template.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account 
* A Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>

</code>

</p>

</a>

</code>

</p>

| Key | Datatype | Required | Description |
| `custom_query_fields` | string |  | This field provides the name of the field to use to filter the response. For example, if you provide &amp;quot;description&amp;quot; as the value of the field, you will get a response similar to the following: {&amp;ldquo;description&amp;rdquo;: &amp;ldquo;template description&amp;rdquo;}. |
