# Add a setting template

POST {{baseUrl}}/phone/setting_templates


<p>
Creates a Zoom Phone setting template for an account. After creating a phone template, the defined settings will become the default settings for an account.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or enterprise Zoom account 
* A Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:write:setting_template:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">

</a>

</code>

</p>
