# Update phone account settings

PATCH {{baseUrl}}/phone/settings


<p>
Account owners can use this API to update Zoom Phone 
<a href="https://support.zoom.us/hc/en-us/articles/360025846692">
account settings
</a>
.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account
</p>
