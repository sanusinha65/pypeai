# Create a shared line group

POST {{baseUrl}}/phone/shared_line_groups


<p>
A 
<a href="https://support.zoom.us/hc/en-us/articles/360038850792">
shared line group
</a>
 allows Zoom Phone admins to share a phone number and extension with a group of phone users or common area phones. This gives members of the shared line group access to the group&#39;s direct phone number and voicemail. Use this API to create a shared line group.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
</p>

</li>

</li>


</ul>
