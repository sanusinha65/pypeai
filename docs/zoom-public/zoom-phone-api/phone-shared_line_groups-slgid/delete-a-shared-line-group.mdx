# Delete a shared line group

DELETE {{baseUrl}}/phone/shared_line_groups/:slgId


<p>
Deletes a shared line group. A 
<a href="https://support.zoom.us/hc/en-us/articles/360038850792">
shared line group
</a>
 allows Zoom Phone admins to share a phone number and extension with a group of phone users or common areas. 

<strong>
Prerequisites:
</strong>
   
</p>



<ul>


<li>
Pro or higher account with Zoom Phone license.
</li>


<li>
Account owner or admin privileges 
</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:delete:shared_line_group:admin
</code>

</p>

</a>
