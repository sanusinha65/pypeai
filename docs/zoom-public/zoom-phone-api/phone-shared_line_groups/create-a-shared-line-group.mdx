# Create a shared line group

POST {{baseUrl}}/phone/shared_line_groups


<p>
Creates a shared line group. A 
<a href="https://support.zoom.us/hc/en-us/articles/360038850792">
shared line group
</a>
 allows Zoom Phone admins to share a phone number and extension with a group of phone users or common areas. This gives members of the shared line group access to the group&#39;s direct phone number and voicemail. 
<strong>
Prerequisites:
</strong>
    * Pro or higher account with Zoom Phone license.* Account owner or admin privileges 
</p>



<p>

<strong>
Scopes:
</strong>

</code>

</p>
