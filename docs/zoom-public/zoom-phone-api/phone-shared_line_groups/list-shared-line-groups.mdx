# List shared line groups

GET {{baseUrl}}/phone/shared_line_groups?page_size=30&amp;next_page_token=&lt;string&gt;


<p>
Lists all the shared line groups. A 
<a href="https://support.zoom.us/hc/en-us/articles/360038850792">
shared line group
</a>
 allows Zoom Phone admins to share a phone number and extension with a group of phone users or common areas. This capability gives members of the shared line group access to the group&#39;s direct phone number and voicemail. 
</p>

Prerequisites:

<br>

</li>


</ul>
