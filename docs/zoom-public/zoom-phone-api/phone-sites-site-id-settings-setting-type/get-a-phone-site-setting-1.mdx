# Get a phone site setting

GET {{baseUrl}}/phone/sites/:siteId/settings/:settingType


<p>
Sites allow you to organize Zoom Phone users in your organization. Use this API to get site setting about a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360020809672">
site
</a>
 according to the setting type.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
</p>



<ul>


<li>
Account must have a Pro or a higher plan with Zoom Phone license.
</li>


<li>
Multiple sites must be 
<a href="https://support.zoom.us/hc/en-us/articles/360020809672-Managing-Multiple-Sites#h_05c88e35-1593-491f-b1a8-b7139a75dc15">
enabled
</a>
.
</li>


</ul>



<p>

<strong>
Scope:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
