# Delete a phone site

DELETE {{baseUrl}}/phone/sites/:siteId?transfer_site_id=8f71O6rWT8KFUGQmJIFAdQ


<p>
Sites allow you to organize Zoom Phone users in your organization. Use this API to delete a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360020809672">
site
</a>
 in a Zoom account. To delete a site, in the query parameter, you must provide The site ID of another site where the assets of current site (users, numbers and phones) can be transferred to.  You cannot use this API to delete the main site.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
</p>

<li>

</li>


<li>

<a href="https://support.zoom.us/hc/en-us/articles/360020809672-Managing-Multiple-Sites">
Multiple sites
</a>
 must be enabled.
</li>


</ul>
