# Delete users from a directory of a site

DELETE {{baseUrl}}/phone/sites/:siteId/dial_by_name_directory/extensions?site_id=&lt;string&gt;&amp;extension_ids=&lt;string&gt;&amp;extension_ids=&lt;string&gt;


<p>
Use this API to delete users from a 
<a href="https://support.zoom.us/hc/en-us/articles/4404938949389-Using-a-dial-by-name-directory">
directory
</a>
 of the specified site.
</p>

### Request Params
| Key | Datatype | Required | Description |
| `site_id` | string |  | Unique identifier of the [site](https://support.zoom.us/hc/en-us/articles/360020809672-Managing-multiple-sites) to which users to delete belongs |
| `extension_ids` | string |  | Extension Ids. If the value is not specified, delete the value of `site_id` from  `included sites` and delete all users related with `site_id` from directory |
| `extension_ids` | string |  | Extension Ids. If the value is not specified, delete the value of `site_id` from  `included sites` and delete all users related with `site_id` from directory |
