# Delete a site setting

DELETE {{baseUrl}}/phone/sites/:siteId/settings/:settingType?device_type=&lt;string&gt;&amp;holiday_id=&lt;string&gt;


<p>
Sites allow you to organize Zoom Phone users in your organization. Use this API to delete the site setting of a specific 
<a href="https://support.zoom.us/hc/en-us/articles/360020809672">
site
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* Account must have a Pro or a higher plan with Zoom Phone license.
* Multiple sites must be 
<a href="https://support.zoom.us/hc/en-us/articles/360020809672-Managing-Multiple-Sites#h_05c88e35-1593-491f-b1a8-b7139a75dc15">
enabled
</a>
.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:delete:site_setting:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `device_type` | string |  | The device type. Enable SRTP AES-256 encryption on the site for the specified device type. Used for `security` setting type. |
| `holiday_id` | string |  | The holiday hour setting ID.  Used for `holiday_hours` setting type. |
