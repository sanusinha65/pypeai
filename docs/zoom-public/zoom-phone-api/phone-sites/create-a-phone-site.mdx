# Create a phone site

POST {{baseUrl}}/phone/sites


<p>
Sites allow you to organize Zoom Phone users in your organization. Use this API to create a 
<a href="https://support.zoom.us/hc/en-us/articles/360020809672">
site
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Multiple sites must be 
<a href="https://support.zoom.us/hc/en-us/articles/360020809672-Managing-Multiple-Sites#h_05c88e35-1593-491f-b1a8-b7139a75dc15">
enabled
</a>
.
* Pro or a higher account with Zoom Phone enabled.
</p>



<p>

<strong>
Scope:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>
