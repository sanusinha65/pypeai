# List phone sites

GET {{baseUrl}}/phone/sites?page_size=30&amp;next_page_token=BJLYC6PABbAHdjwSkGVQeeR6B1juwHqj3G2


<p>
Sites allow you to organize Zoom Phone users in your organization. Use this API to list all the 
<a href="https://support.zoom.us/hc/en-us/articles/360020809672">
sites
</a>
 that have been created for an account.
<br>


<strong>
Prerequisites:
</strong>

<br>

* Multiple Sites must be 
<a href="https://support.zoom.us/hc/en-us/articles/360020809672-Managing-Multiple-Sites#h_05c88e35-1593-491f-b1a8-b7139a75dc15">
enabled
</a>
.
* Pro or a higher account with Zoom Phone enabled.
</p>



<p>

<strong>
Scope:
</strong>
 
<code>
phone:read:admin
</code>

<br>
 
 
<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
