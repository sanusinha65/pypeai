# Get SMS by message ID

GET {{baseUrl}}/phone/sms/sessions/:sessionId/messages/:messageId


<p>
Get details about a specific message in an SMS session.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone_sms:read
</code>
, 
<code>
phone_sms:read:admin
</code>
, 
<code>
phone_sms:master
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Heavy
</code>

</p>

<strong>
Prerequisites

* Paid account
* User-enabled Zoom phone
