# Assign a phone number to SMS campaign

POST {{baseUrl}}/phone/sms_campaigns/:smsCampaignId/phone_numbers


<p>
Use this API to 
<a href="https://support.zoom.us/hc/en-us/articles/5016496738445-SMS-MMS-10DLC-Compliance-for-Zoom-Phone-and-Zoom-Contact-Center#h_01FYVVQM1WMW5JD48YNY3J581B">
assign a phone number to the SMS campaign
</a>
.
</p>



<p>

<strong>
Prerequisites:
