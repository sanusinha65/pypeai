# Batch add users

POST {{baseUrl}}/phone/users/batch


<p>
Adds phone users in batch. You can add up to 10 users at a time.
</p>



<p>

<strong>
Prerequisites:
</strong>

* The users must be active in your 
<a href="https://marketplace.zoom.us/docs/api-reference/zoom-api/methods#tag/Users/operation/users">
Zoom account
</a>
. 
* Pro or higher account plan with Zoom phone license
* Account owner or admin permissions
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:write:batch_users:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
