# Update multiple users&#39; properties in batch

PUT {{baseUrl}}/phone/users/batch


<p>
Updates multiple users&#39; properties in batch. For example, you can update the users&#39; 
<a href="https://support.zoom.us/hc/en-us/articles/360020809672">
site
</a>
 when 
<code>
batchType
</code>
 is equal to 
<code>
move_site
</code>
. You can update 10 users at a time. 
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business, or Education account
* Zoom Phone license 
</p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>

</p>



<p>

<strong>

</p>
