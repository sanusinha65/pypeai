# Add an audio item for text-to-speech conversion

POST {{baseUrl}}/phone/users/:userId/audios


<p>
Use this API to add an audio item for 
<a href="https://support.zoom.us/hc/en-us/articles/4402414203533-Using-the-audio-library-to-customize-audio#h_01F8B0D2ZJBKEDH10DFZ7J2CM7">
text-to-speech conversion
</a>
.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write
</code>
,
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Rate Limit Label:
</strong>
 
<code>
Light
</code>

</p>





### Request Body
```
{&quot;audio_name&quot;=&gt;&quot;hello.mp3&quot;, &quot;text&quot;=&gt;&quot;hello&quot;, &quot;voice_language&quot;=&gt;&quot;en-US&quot;, &quot;voice_accent&quot;=&gt;&quot;Joanna-Female&quot;}
```

### HEADERS
| Key | Datatype | Required | Description |
| `Content-Type` | string |  |  |
| `Accept` | string |  |  |


### RESPONSES

**status**: `Created`
```
{&quot;audio_id&quot;:&quot;fPOSdWWqRVqhohLYs7TW9Q&quot;,&quot;name&quot;:&quot;hello.mp3&quot;}
```
