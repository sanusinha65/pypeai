# Add audio items

POST {{baseUrl}}/phone/users/:userId/audios/batch


<p>
Use this API to add audio items. You can only upload voice files at this time.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write
</code>
,
<code>
phone:write:admin
</code>

</p>



<p>

<strong>
Rate Limit Label:
</strong>
 
<code>
Heavy
</code>

</p>



<p>

<strong>
Size and quantity limits for audio attachments:
</strong>

* Up to 5 attachments
* Each file size should be no more than 1MB
</p>
