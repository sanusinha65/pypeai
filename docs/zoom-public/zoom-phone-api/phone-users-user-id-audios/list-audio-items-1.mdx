# List audio items

GET {{baseUrl}}/phone/users/:userId/audios


<p>
Use this API to get audio items.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read
</code>
,
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Rate Limit Label:
</strong>
 
<code>
Light
</code>

</p>
