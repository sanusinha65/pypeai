# Delete a user&#39;s call log

DELETE {{baseUrl}}/phone/users/:userId/call_logs/:callLogId


<p>
Use this API to delete a user&#39;s 
<a href="https://support.zoom.us/hc/en-us/articles/360021114452-Viewing-and-identifying-logs">
call log
</a>
. For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>

<strong>
Prerequisites:

* User must belong to a Business or Enterprise account

</p>
