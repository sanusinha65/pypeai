### Request Params
| Key | Datatype | Required | Description |
| `sync_type` | string |  | Options for synchronizing call log:&lt;br&gt;
FSync - Full sync&lt;br&gt;
ISync - Increase sync&lt;br&gt;
BSync - Backward sync |
| `count` | number |  | The number of records returned within a single API call. |
| `sync_token` | string |  | The time range for returned records. Used for locating where the next retrieval will begin. |
