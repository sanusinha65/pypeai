# Update a user setting

PATCH {{baseUrl}}/phone/users/:userId/settings/:settingType


<p>
Use this API to update the user setting according to the setting type, specifically for a shared voicemail access and delegation. For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>
Phone users can access 
<a href="https://support.zoom.us/hc/en-us/articles/360033863991-Sharing-and-controlling-access-to-a-voicemail-inbox">
shared voicemail inboxes
</a>
 in the Zoom desktop client, web portal, or provisioned desk phone.
</p>



<p>
To view these settings in the Zoom web portal, navigate to the 
<strong>
Admin &gt;&gt; Phone System Management &gt;&gt; Users &amp; Rooms
</strong>
 interface. Click the 
<strong>
Users
</strong>
 tab and select 
<strong>
User Settings
</strong>
. Scroll down to 
<strong>
Voicemail &amp; Call Recordings
</strong>
.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>


<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account
</p>
