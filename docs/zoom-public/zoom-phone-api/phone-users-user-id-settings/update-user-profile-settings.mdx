# Update user profile settings

PATCH {{baseUrl}}/phone/users/:userId/settings


<p>
Use this API to update the Zoom Phone 
<a href="https://support.zoom.us/hc/en-us/articles/360021325712-Configuring-Settings">
profile settings
</a>
 of a user. For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>

<strong>

<code>

,

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
