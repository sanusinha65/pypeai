# Get user&#39;s profile

GET {{baseUrl}}/phone/users/:userId


<p>
Use this API to return a user&#39;s 
<a href="https://support.zoom.us/hc/en-us/articles/360001297663-Quickstart-Guide-for-Zoom-Phone-Administrators">
Zoom phone
</a>
 profile. For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read
</code>
, 
<code>
phone:read:admin
</code>


<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>

 * A Business or Enterprise account 
* A Zoom Phone license
</p>
