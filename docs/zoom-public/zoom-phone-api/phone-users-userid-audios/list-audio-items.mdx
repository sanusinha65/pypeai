# List audio items

GET {{baseUrl}}/phone/users/:userId/audios


<p>
Returns personal audios. Only the admin or user can query your audios and directly pass the 
<code>
me
</code>
 value instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>

<strong>
Prerequisites:
</strong>

* Business or Education account
* Zoom Phone license 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read
</code>
,
<code>
phone:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:list_audios
</code>
,
<code>
phone:read:list_audios:admin
</code>

</p>
