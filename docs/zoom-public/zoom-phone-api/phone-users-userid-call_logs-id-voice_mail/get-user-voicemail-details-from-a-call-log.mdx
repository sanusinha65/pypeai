# Get user voicemail details from a call log

GET {{baseUrl}}/phone/users/:userId/call_logs/:id/voice_mail


<p>
Use this API to return detailed information on a voicemail associated with a call log ID. For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* User must belong to a Business or Enterprise account 
* User must have a Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read
</code>
,
<code>
phone:read:admin
</code>
,
<code>
phone_voicemail:read
</code>
,
<code>
phone_voicemail:read:admin
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:voicemail
</code>
,
<code>
phone:read:voicemail:admin
</code>

</p>

<strong>
