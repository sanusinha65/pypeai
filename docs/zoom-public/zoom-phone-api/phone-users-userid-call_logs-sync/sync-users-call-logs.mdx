# Sync user&#39;s call logs

GET {{baseUrl}}/phone/users/:userId/call_logs/sync?sync_type=BSync&amp;count=&lt;integer&gt;&amp;sync_token=&lt;string&gt;


<p>
Syncs a user&#39;s 
<a href="https://support.zoom.us/hc/en-us/articles/360001297663-Quickstart-Guide-for-Zoom-Phone-Administrators">
Zoom phone
</a>
 call logs. For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account 
* A Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>
,
<code>
phone:read
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>
 
<code>
phone:read:list_call_logs
</code>
,
<code>
phone:read:list_call_logs:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `sync_type` | string |  | Options for synchronizing call log:  
 
FSync - Full sync  
 
ISync - Increase sync  
 
BSync - Backward sync |
| `count` | string |  | The number of records returned within a single API call. |
| `sync_token` | string |  | The time range for returned records. Used for locating where the next retrieval will begin. |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
