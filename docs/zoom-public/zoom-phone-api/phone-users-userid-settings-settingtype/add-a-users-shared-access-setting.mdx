# Add a user&#39;s shared access setting

POST {{baseUrl}}/phone/users/:userId/settings/:settingType


<p>
Adds the user setting according to the setting type, specifically for delegation, intercom and shared access for voicemail, and call recordings. For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>
To see the shared access settings in the Zoom web portal, go to 
<strong>
Admin &gt; Phone System Management &gt; Users &amp; Rooms
</strong>
 . Click 
<strong>
Users
</strong>
 and select 
<strong>
User Policy
</strong>
. Go to 
<strong>
Voicemail, Automatic Call Recording and Ad Hoc Call Recording
</strong>
.
</p>



<p>
To view the delegation and intercom setting in your Zoom web portal, navigate to 
<strong>
Admin &gt; Phone System Management &gt; Users &amp; Rooms
</strong>
. Click the 
<strong>
Users
</strong>
 tab and select 
<strong>
User Settings
</strong>

</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>
,
<code>
phone:write
</code>

</p>



<p>

<strong>
Granular Scopes:
</strong>

phone:write:shared_setting
</code>
,
<code>
phone:write:shared_setting:admin
</code>

</p>

</p>
