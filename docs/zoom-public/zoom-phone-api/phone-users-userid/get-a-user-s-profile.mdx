# Get a user&#39;s profile

GET {{baseUrl}}/phone/users/:userId


<p>
Returns a user&#39;s 
<a href="https://support.zoom.us/hc/en-us/articles/360001297663-Quickstart-Guide-for-Zoom-Phone-Administrators">
Zoom phone
</a>

<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>

<code>

</code>
