# Update a user&#39;s profile

PATCH {{baseUrl}}/phone/users/:userId


<p>
Updates a user&#39;s 
<a href="https://support.zoom.us/hc/en-us/categories/360001370051-Zoom-Phone">
Zoom Phone
</a>
 profile. For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>
To add, update or remove the shared access members for voicemail and call recordings, use the 
<a href="https://marketplace.zoom.us/docs/api-reference/phone/methods#tag/Users/operation/addUserSetting">
Add
</a>
/
<a href="https://marketplace.zoom.us/docs/api-reference/phone/methods#tag/Users/operation/updateUserSetting">
Update
</a>
/
<a href="https://marketplace.zoom.us/docs/api-reference/phone/methods#tag/Users/operation/deleteUserSetting">
Delete
</a>
 a user&#39;s shared access setting API. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise account 
* A Zoom Phone license
</p>

<strong>
Scopes:

,
<code>
phone:write:admin
</code>
