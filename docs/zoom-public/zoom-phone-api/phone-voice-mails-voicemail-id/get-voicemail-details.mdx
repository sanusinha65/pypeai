# Get voicemail details

GET {{baseUrl}}/phone/voice_mails/:voicemailId


<p>
Use this API to return information about a 
<a href="https://support.zoom.us/hc/en-us/articles/360021400211-Managing-voicemail-messages">
voicemail message
</a>
.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>
, 
<code>
phone:read
</code>
, 
<code>
phone_voicemail:read
</code>
, 
<code>
phone_voicemail:read:admin
</code>


<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Zoom Phone license
</p>
