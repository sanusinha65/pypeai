# Add BYOC phone numbers

POST {{baseUrl}}/phone/byoc_numbers


<p>
Use this API to add BYOC (Bring Your Own Carrier) phone numbers to Zoom Phone.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:write:admin
</code>
, 
<code>
phone:write
</code>
, or 
<code>
phone:master
</code>

</br>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Light
</code>

</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Business or Enterprise plan 
* A Zoom Phone license
</p>
