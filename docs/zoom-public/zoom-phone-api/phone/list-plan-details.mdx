# List plan details

GET {{baseUrl}}/phone/plans


<p>
Use this API to return all of an account&#39;s Zoom Phone 
<a href="https://marketplace.zoom.us/docs/api-reference/other-references/plans#additional-zoom-phone-plans-and-codes">
plan package
</a>
, phone number usage and availability.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or a higher account 
* A Zoom Phone license
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
phone:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
