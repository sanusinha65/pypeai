#Zoom QSS API

Number of APIs: 3


<p>

<a href="https://explore.zoom.us/en/qss/">
Zoom Quality of Service Subscription (QSS)
</a>
 is an add-on product that enables Developers to receive details about the network traffic in near real-time for users, hosts, and participants in their meetings, webinars, and phone calls. This data can be used to proactively troubleshoot and identify issues as quickly as possible. 
<a href="https://explore.zoom.us/en/contactsales/">
Contact Zoom Sales
</a>
 to add this feature.
</p>



<h5>
Prerequisites:
</h5>



<p>
In addition to having the QSS product on your account, at least one user on the account must have Developer permissions enabled to be able to create an application that can subscribe to QSS events. This user should create a Zoom app to receive notifications.
</p>



1. [metrics-meetings-{meetingId}-participants-qos_summary - List meeting participants QoS Summary](https://developers.qodex.ai/zoom-public/zoom-qss-api/metrics-meetings-meetingid-participants-qos_summary/list-meeting-participants-qos-summary)
GET {{baseUrl}}/metrics/meetings/:meetingId/participants/qos_summary?page_size=1&amp;next_page_token=&lt;string&gt;


2. [videosdk-sessions-{sessionId}-users-qos_summary - List session users QoS Summary](https://developers.qodex.ai/zoom-public/zoom-qss-api/videosdk-sessions-sessionid-users-qos_summary/list-session-users-qos-summary)
GET {{baseUrl}}/videosdk/sessions/:sessionId/users/qos_summary?page_size=1&amp;next_page_token=&lt;string&gt;


3. [metrics-webinars-{webinarId}-participants-qos_summary - List webinar participants QoS Summary](https://developers.qodex.ai/zoom-public/zoom-qss-api/metrics-webinars-webinarid-participants-qos_summary/list-webinar-participants-qos-summary)
GET {{baseUrl}}/metrics/webinars/:webinarId/participants/qos_summary?page_size=1&amp;next_page_token=&lt;string&gt;
