# Upload iq file.

POST {{baseUrl}}/iq/files


<p>
Upload a file to Zoom IQ. 
</p>



<p>

<strong>
Prerequisite:
</strong>

<br>

 The caller must be an iq_licensed user.
</p>



<p>

<strong>
Note:
</strong>

<br>

* Base URL: 
<code>
https://fileapi.zoom.us/v2/
</code>
.
<br>

* Rate limit: 20 requests per second or 2000 requests per day per IP address. 
* The caller must support HTTP 30x redirects. 
* The caller must retain the authorization header when redirected to a different hostname. 
</p>



<ul>


<li>
Supported video formats: 
<code>
.mov
</code>
, 
<code>
.mp4
</code>
, 
<code>
.avi
</code>
, 
<code>
.wmv
</code>
 or 
<code>
H.264
</code>
.
</li>


<li>
Supported transcript and file attachment format: 
<code>
.json
</code>
 .  The fileName must end with 
<code>
transcript.json
</code>
.
</li>


<li>
Supported metadata and file attachment format: 
<code>
.json
</code>
. The fileName must end with 
<code>
metadata.json
</code>
.
</li>


<li>
Required file upload sequence: main file, transcript file (if necessary), metadata file (if necessary).
</li>


<li>
When your object size reaches 2 GB, you should use multipart uploads instead of uploading the object in a single operation.
</li>


<li>
For an 
<strong>
account-level
</strong>
 
<a href="https://developers.zoom.us/docs/integrations/create/">
OAuth app
</a>
, this API can only be used on behalf of a user who is assigned with a 
<a href="https://support.zoom.us/hc/en-us/articles/115001078646-Using-role-management#:%7E:text=Each%20user%20in%20a%20Zoom,owner%2C%20administrator%2C%20or%20member.&amp;text=Role%2Dbased%20access%20control%20enables,needs%20to%20view%20or%20edit.">
role
</a>
 with 
<strong>
Edit
</strong>
 permission for 
<strong>
All Conversations
</strong>
.
</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
iq_conversation:write:admin
</code>
,
<code>
iq_conversation:write
</code>

</p>
