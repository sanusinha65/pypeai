# Delete a calendar resource

DELETE {{baseUrl}}/rooms/calendar/services/:serviceId/resources/:resourceId


<p>
Use this API to delete a Zoom Room account&#39;s 
<a href="https://support.zoom.us/hc/en-us/articles/4409832833037">
calendar resource
</a>
 from a Microsoft Exchange or Office 365 calendar service. 
</p>



<p>

<strong>
Note:
</strong>
 This API does not support deleting a calendar resource from a Google calendar service. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or a higher plan with a 
<a href="https://zoom.us/zoomrooms">
Zoom Rooms
</a>
 license.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
room:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
