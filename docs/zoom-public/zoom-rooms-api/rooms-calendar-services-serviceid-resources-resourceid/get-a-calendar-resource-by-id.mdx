# Get a calendar resource by ID

GET {{baseUrl}}/rooms/calendar/services/:serviceId/resources/:resourceId


<p>
Use this API to get a Zoom Room account&#39;s 
<a href="https://support.zoom.us/hc/en-us/articles/4409832833037">
calendar resource
</a>
