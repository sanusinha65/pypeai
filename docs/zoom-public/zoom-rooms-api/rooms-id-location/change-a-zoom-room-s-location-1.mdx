# Change a Zoom Room&#39;s location

PUT {{baseUrl}}/rooms/:id/location


<p>
An account owner of a Zoom account can establish a 
<a href="https://support.zoom.us/hc/en-us/articles/115000342983-Zoom-Rooms-Location-Hierarchy">
Zoom Rooms Location Hierarchy
</a>
 to better organize Zoom Rooms spread across various locations. The location can be structured in a hierarchy with Country being the top-level location, followed by city, campus, building, and floor. Use this API to assign a new location for a Zoom Room. Note that the Zoom Room can be assigned only to the lowest level location available in the hierarchy.
