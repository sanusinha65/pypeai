# Get Zoom Room settings

GET {{baseUrl}}/rooms/:id/settings?setting_type=meeting


<p>
Get information on meeting or alert settings applied to a specific Zoom Room. By default, only 
<strong>
Meeting Settings
</strong>
 are returned. To view only 
<strong>
Alert Settings
</strong>
, specify 
<code>
alert
</code>
 as the value of the 
<code>
setting_type
</code>
 query parameter.  
</p>



<p>

<strong>
Prerequisites:
</strong>
  
</p>



<ul>


<li>
Zoom Room licenses
</li>


<li>
Owner or Admin privileges on the Zoom Account.
<br>

</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
room:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
MEDIUM
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `setting_type` | string |  | (Required) The type of setting that you would like to retrieve.  
  `alert`: Alert Settings applied on the Zoom Rooms Account.  
 
`meeting`: Meeting settings of the Zoom Rooms Account. |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
