# Update Zoom Rooms location structure

PUT {{baseUrl}}/rooms/locations/structure


<p>
Update the 
<a href="https://support.zoom.us/hc/en-us/articles/115000342983-Zoom-Rooms-Location-Hierarchy">
location hierarchial structure(s)
</a>

</p>

<strong>
Prerequisites:

</li>


</ul>

room:write:admin
