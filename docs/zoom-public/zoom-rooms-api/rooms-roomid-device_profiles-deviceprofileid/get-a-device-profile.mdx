# Get a device profile

GET {{baseUrl}}/rooms/:roomId/device_profiles/:deviceProfileId


<p>
Use this API to return a Zoom Room device profile. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or a higher account with Zoom Rooms.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
room:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
