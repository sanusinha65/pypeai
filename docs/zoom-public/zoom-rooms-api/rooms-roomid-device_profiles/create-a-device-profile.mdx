# Create a device profile

POST {{baseUrl}}/rooms/:roomId/device_profiles


<p>
Use this API to create a Zoom Room device profile. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro or a higher account with Zoom Rooms.
</p>

<strong>
Scopes:
</strong>
 
<code>
room:write:admin
</code>

</p>
