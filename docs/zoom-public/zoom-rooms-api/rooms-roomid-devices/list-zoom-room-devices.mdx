# List Zoom Room devices

GET {{baseUrl}}/rooms/:roomId/devices


<p>
List information about the devices that are being used for a specific 
<a href="https://support.zoom.us/hc/en-us/articles/207483343-Getting-Started-with-Zoom-Rooms">
Zoom Room
</a>
 in an account.
</p>



<p>

<strong>
Prerequisites:
</strong>
  
</p>



<ul>


<li>

<p>
Pro or a higher plan with 
<a href="https://zoom.us/zoomrooms">
Zoom Room
</a>
 license.  
</p>

</li>


<li>

<p>
Account owner or admin permissions.
</p>

</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
room:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
