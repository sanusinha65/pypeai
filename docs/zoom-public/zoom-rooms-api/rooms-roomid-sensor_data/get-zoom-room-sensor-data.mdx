# Get Zoom Room sensor data

GET {{baseUrl}}/rooms/:roomId/sensor_data?from=&lt;string&gt;&amp;to=&lt;string&gt;&amp;page_size=30&amp;next_page_token=&lt;string&gt;&amp;device_id=&lt;string&gt;&amp;sensor_type=CO2


<p>
Use this API to get the sensor data from the specified Zoom Room.   
</p>



<p>

<strong>
Prerequisites:
</strong>
  
</p>



<ul>


<li>
Zoom Room licenses
</li>


<li>
Owner or Admin privileges on the Zoom Account.
<br>

</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
room:read:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>

| Key | Datatype | Required | Description |
| `from` | string |  | (Required) The start time and date in &#39;yyyy-MM-ddTHH:dd:ssZ&#39; format. |
| `to` | string |  | (Required) The end time and date in &#39;yyyy-MM-ddTHH:dd:ssZ&#39; format. |
| `page_size` | number |  | The number of records returned within a single API call. |
| `next_page_token` | string |  | Use the next page token to paginate through large result sets. A next page token is returned whenever the set of available results exceed the current page size. This token&#39;s expiration period is 15 minutes. |
| `device_id` | string |  |  |
| `sensor_type` | string |  |  |
