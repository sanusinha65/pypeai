# Un-assign Tags from a Zoom Room

DELETE {{baseUrl}}/rooms/:roomId/tags?tag_ids=&lt;string&gt;


<p>
Use this API to un-assign Tags from a Zoom Room 
</p>

### Request Params
| Key | Datatype | Required | Description |
| `tag_ids` | string |  | (Required) The Tag ID(s) to un-assign from the Zoom Room.  Enter `all` to un-assign all tags from a Zoom Room.  Currently, only one Tag ID per request is allowed. |
