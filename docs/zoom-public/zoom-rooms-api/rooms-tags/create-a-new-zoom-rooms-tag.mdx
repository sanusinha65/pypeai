# Create a new Zoom Rooms Tag

POST {{baseUrl}}/rooms/tags


<p>
Use this API to create a new Zoom Rooms Tag. 
</p>

<strong>

* A Pro or a higher plan with a 
<a href="https://zoom.us/zoomrooms">
Zoom Rooms
</a>
