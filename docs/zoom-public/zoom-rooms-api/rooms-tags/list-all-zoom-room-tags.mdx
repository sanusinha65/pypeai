# List all Zoom Room Tags

GET {{baseUrl}}/rooms/tags?page_size=30&amp;next_page_token=&lt;string&gt;


<p>
Use this API to list all Zoom Rooms Tags

### Request Params
| Key | Datatype | Required | Description |
| `page_size` | number |  | The number of records returned within a single API call. |
| `next_page_token` | string |  | (Required) The next page token is used to paginate through large result sets. A next page token will be returned whenever the set of available results exceeds the current page size. The expiration period for this token is 15 minutes. |
