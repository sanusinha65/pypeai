#Zoom SCIM2 API

Number of APIs: 11


<p>
SCIM2 (System for Cross-domain Identity Management) is a specification designed to automate the provisioning of user/group identities across various cloud-based applications and services using SSO services and Identity Providers. The Zoom SCIM2 API provides support for user/group provisioning through the 
<strong>
User/Group
</strong>
 resource. Each SCIM2 API endpoint has a rate limit of 1 request/second per account.
</p>



<p>
SCIM uses HTTP methods that is compatible to REST architecture style. The payloads require schema definitions, attributes, and values for request. Also using the SCIM API, you can use additional features such as attribute filters and search criteria.
</p>



<p>
While using the SCIM APIs, set the value of the Accept header as 
<code>
application/scim+json
</code>
.
</p>

<h2>
Authentication
</h2>



<p>
The SCIM2 API supports OAuth authentication. To use Oauth 2.0, create an 
<a href="https://marketplace.zoom.us/docs/guides/build/oauth-app">
OAuth app
</a>
 or a 
<a href="https://marketplace.zoom.us/docs/guides/build/server-to-server-oauth-app">
Server-to-Server OAuth app
</a>
 on the Zoom App Marketplace and select 
<code>
SCIM2
</code>
 as the scope for your app. Next, 
<a href="https://developers.zoom.us/docs/integrations/oauth/">
generate an OAuth token
</a>
 for your app and start making SCIM2 API calls.
</p>
