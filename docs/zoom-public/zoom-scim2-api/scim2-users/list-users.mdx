# List users

GET {{baseUrl}}/scim2/Users?startIndex=1&amp;count=1&amp;filter=&lt;string&gt;


<p>
Use this API to list all users. You can include additional query parameters to filter the response. 
</p>

### Request Params
| Key | Datatype | Required | Description |
| `startIndex` | number |  | (Required) The start index of records to be returned. |
| `count` | number |  | The number of records returned in a single API call. |
| `filter` | string |  | The type of query: 
* `userName eq {userEmail}` — Provide the user&#39;s email address to filter the response to a specific user. 
* `license type` — Filter the response by license type. 
* `externalId eq {userId}` — Filter the response by the user&#39;s ID (`userId`). |
