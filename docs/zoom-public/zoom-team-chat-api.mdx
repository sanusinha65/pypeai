#Zoom Team Chat API

Number of APIs: 40


<p>
The Zoom Team Chat API allows developers to access information from Zoom. You can use this API to build private services or public applications on the 
<a href="http://marketplace.zoom.us">
Zoom App Marketplace
</a>
. To learn how to get your credentials and create private/public applications, read our 
<a href="https://developers.zoom.us/docs/integrations/oauth/">
OAuth
</a>
 documentation. All endpoints are available via 
<code>
https
</code>
 and are located at 
<code>
api.zoom.us/v2/
</code>
.
</p>
