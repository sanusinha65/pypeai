# Join a channel

POST {{baseUrl}}/chat/channels/:channelId/members/me


<p>
Joins a channel that is open for anyone in the same organization to join. A 
<a href="https://support.zoom.us/hc/en-us/articles/200912909-Getting-Started-With-Channels-Group-Messaging-">
channel
</a>
 can have one or more members. You cannot use this API to join private channels that only allow invited members to be a part of them.
</p>



<p>

<p style="background-color:#e1f5fe; color:#01579b; padding:8px">

OAuth apps
