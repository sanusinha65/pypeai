# Batch remove members from a channel

DELETE {{baseUrl}}/chat/channels/:channelId/members?member_ids=&lt;string&gt;&amp;user_ids=&lt;string&gt;


<p>
Batch removes multiple members from a chat channel. A 
<a href="https://support.zoom.us/hc/en-us/articles/200912909-Getting-Started-With-Channels-Group-Messaging-">
channel
</a>
 can have one or many members.

| `user_ids` | string |  | (Required) The members&#39; member IDs or user IDs. Use commas (,) to separate a supported maximum of 20 IDs. |
