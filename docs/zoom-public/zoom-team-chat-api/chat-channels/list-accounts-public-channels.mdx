# List account&#39;s public channels

GET {{baseUrl}}/chat/channels?page_size=10&amp;next_page_token=&lt;string&gt;


<p>
Lists public chat channels created by an account&#39;s users. 
</p>



<p>

<strong>
Note:
</strong>
 This API only supports account-level apps. The user calling this API must have a 
<a href="https://support.zoom.us/hc/en-us/articles/115001078646-Using-role-management">
role
</a>
 that has the 
<strong>
View
</strong>
 or 
<strong>
Edit
</strong>
 permission for the 
<strong>
Chat Channels
</strong>
 feature. 
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
chat_channel:read:admin
</code>
 
<br>
 
<strong>

<a href="https://developers.zoom.us/docs/api/rest/rate-limits/">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>



### Request Params
| Key | Datatype | Required | Description |
| `page_size` | number |  | The number of records returned per page in a single API call. |
| `next_page_token` | string |  | The next page token paginates through a large set of results. A next page token is returned whenever the set of available results exceeds the current page size. This token&#39;s expiration period is 15 minutes. |



### HEADERS
| Key | Datatype | Required | Description |
| `Accept` | string |  |  |
