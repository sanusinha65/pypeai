# Get user&#39;s contact details

GET {{baseUrl}}/chat/users/me/contacts/:identifier?query_presence_status=&lt;boolean&gt;


<p>
A user under an organization&#39;s Zoom account has internal users listed under Company Contacts in the Zoom Client. A Zoom user can also add another Zoom user as a 
<a href="https://support.zoom.us/hc/en-us/articles/115004055706-Managing-Contacts">
contact
</a>
. Call this API to get information on a specific contact of the Zoom user.
</p>



<p>

<p style="background-color:#e1f5fe; color:#01579b; padding:8px">

user-managed

OAuth app
</a>
.

### Request Params
| Key | Datatype | Required | Description |
| `query_presence_status` | string |  | The presence status of the contact. 
Include this query parameter with a value of `true` to get the presence status of the contact in the response. |

| Key | Datatype | Required | Description |
