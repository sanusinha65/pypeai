# List user&#39;s contacts

GET {{baseUrl}}/chat/users/me/contacts?type=company&amp;page_size=10&amp;next_page_token=&lt;string&gt;


<p>
A user under an organization&#39;s Zoom account has internal users listed under Company Contacts in the Zoom Client. A Zoom user can also add another Zoom user as a 
<a href="https://support.zoom.us/hc/en-us/articles/115004055706-Managing-Contacts">
contact
</a>
. Call this API to list all the contacts of a Zoom user. Zoom contacts are categorized into 
<q>
company contacts
</q>
 and 
<q>
external contacts
</q>
. You must specify the contact type in the 
<code>
type
</code>
 query parameter. If you do not specify, by default, the type will be set as company contact.
</p>



<p>

OAuth app
</a>
.
</p>

### Request Params
| Key | Datatype | Required | Description |
| `type` | string |  | The type of contact. The value can be one of the following:
`company`: Contacts from the user&#39;s organization.
`external`: External contacts.  |
| `page_size` | number |  | The number of records returned with a single API call. |
| `next_page_token` | string |  | The next page token is used to paginate through large result sets. A next page token will be returned whenever the set of available results exceeds the current page size. The expiration period for this token is 15 minutes. |

| Key | Datatype | Required | Description |
