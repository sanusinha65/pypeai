# Remove a member

DELETE {{baseUrl}}/chat/users/:userId/channels/:channelId/members/:identifier


<p>
Removes a member from a chat channel. A 
<a href="https://support.zoom.us/hc/en-us/articles/200912909-Getting-Started-With-Channels-Group-Messaging-">
channel
</a>
 can have one or many members.  For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>
