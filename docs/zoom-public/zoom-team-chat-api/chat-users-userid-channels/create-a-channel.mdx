# Create a channel

POST {{baseUrl}}/chat/users/:userId/channels


<p>
Creates a channel for a user. For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>
Zoom chat channels allow users to communicate via chat in private or public groups.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
chat_channel:write
</code>
 or 
<code>
chat_channel:write:admin
</code>

<br>

<strong>

<a href="https://developers.zoom.us/docs/api/rest/rate-limits/">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>



<p style="background-color:#e1f5fe; color:#01579b; padding:8px">
 
<b>
Note:
</b>
 This API supports both user-managed apps and account-level apps. However, in an 
<b>
account-level
</b>
 
<a href="https://marketplace.zoom.us/docs/guides/getting-started/app-types/create-oauth-app">
OAuth app
</a>
, to create a channel on behalf of another user in the same Zoom account, the user calling this API must have a 
<a href="https://support.zoom.us/hc/en-us/articles/115001078646-Using-role-management#:~:text=Each%20user%20in%20a%20Zoom,owner%2C%20administrator%2C%20or%20member.&text=Role%2Dbased%20access%20control%20enables,needs%20to%20view%20or%20edit.">
role
</a>
 that has the 
<b>
Edit
</b>
 permission for the 
<b>
Chat channels
</b>
 feature.
</p>





### Request Body
```
{&quot;channel_settings&quot;=&gt;{&quot;add_member_permissions&quot;=&gt;1, &quot;new_members_can_see_previous_messages_files&quot;=&gt;true, &quot;posting_permissions&quot;=&gt;1, &quot;mention_all_permissions&quot;=&gt;1}, &quot;members&quot;=&gt;[{&quot;email&quot;=&gt;&quot;&lt;email&gt;&quot;}, {&quot;email&quot;=&gt;&quot;&lt;email&gt;&quot;}], &quot;name&quot;=&gt;&quot;&lt;string&gt;&quot;, &quot;type&quot;=&gt;2}
```
