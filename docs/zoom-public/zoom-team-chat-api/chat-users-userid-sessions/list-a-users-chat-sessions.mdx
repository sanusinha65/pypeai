# List a user&#39;s chat sessions

GET {{baseUrl}}/chat/users/:userId/sessions?type=1:1&amp;page_size=10&amp;next_page_token=&lt;string&gt;


<p>

<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me

 value
</a>

<code>

</code>

### Request Params
| Key | Datatype | Required | Description |
| `type` | string |  | The session queried by the chat type. The API only returns sessions of which the user is a member and of the specified chat `type`. 

**Note:** 
* If no `type` is provided, response will contain both group and 1:1 chats. |
| `page_size` | number |  | The number of records returned with a single API call.  |
| `next_page_token` | string |  | The next page token paginates through a large set of results. A next page token is returned whenever the set of available results exceeds the current page size. This token&#39;s expiration period is 15 minutes. |
