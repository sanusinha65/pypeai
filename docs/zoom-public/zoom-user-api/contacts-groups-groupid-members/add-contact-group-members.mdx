# Add contact group members

POST {{baseUrl}}/contacts/groups/:groupId/members


<p>
Use this API to add members to a 
<a href="https://support.zoom.us/hc/en-us/articles/204519819-Group-Management">
contact group
</a>
.
</p>



<p>

<strong>
Prerequisite
</strong>
: Pro or higher account.  
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
contact_group:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Heavy
</code>

</p>
