# Add group admins

POST {{baseUrl}}/groups/:groupId/admins


<p>
Use this API to add administrators to a 
<a href="https://support.zoom.us/hc/en-us/articles/204519819-Group-Management-">
group
</a>
 under your account.
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* A Pro, Business, or Education account
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
group:write:admin
</code>

</p>



<p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">
Rate Limit Label
</a>
:
</strong>
 
<code>
Medium
</code>

</p>
