# Update locked settings

PATCH {{baseUrl}}/groups/:groupId/lock_settings?option=&lt;string&gt;


<p>
Update a 
<a href="https://support.zoom.us/hc/en-us/articles/204519819-Group-Management-">
group&#39;s
</a>
 locked settings. If you lock a setting, the group members cannot modify it individually. 
</p>



<p>

<strong>
Note:
</strong>
 The 
<code>
force_pmi_jbh_password
</code>
 field under meeting settings is deprecated as of September 22, 2019. This field will be replaced by another field that will provide the same functionality.&lt;/p&gt;
</p>



<p>

<strong>
Prerequisite
</strong>
: Pro, Business, or Education account  
</p>

<strong>
Scopes:
</strong>
 
<code>
group:write:admin
</code>

</p>

</a>

MEDIUM
</code>
