# Get a user

GET {{baseUrl}}/users/:userId?login_type=99&amp;encrypted_email=false&amp;search_by_unique_id=&lt;boolean&gt;


<p>
View a user&#39;s information on a Zoom account. For user-managed apps, pass 
<a href="https://developers.zoom.us/docs/api/rest/using-zoom-apis/#the-me-keyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter. 

<strong>
Note:
</strong>
 The 
<code>
user_info:read
</code>
 scope is only available when you pass the 
<code>
me
</code>
 value for the 
<code>
$userId
</code>
 value. 
</p>



<p>
Users who have not activated their account will have a 
<code>
pending
</code>
 status. These users&#39; 
<code>
created_at
</code>
 timestamp will also display the time at which the API call was made, 
<strong>
not
</strong>

</p>

### Request Params
| Key | Datatype | Required | Description |
| `login_type` | number |  | The user&#39;s login method. 
* `0` - Facebook OAuth 
* `1` - Google OAuth. 
* `24` - Apple OAuth. 
* `27` - Microsoft OAuth. 
* `97` - Mobile device. 
* `98` - RingCentral OAuth. 
* `99` - API user. 
* `100` - Zoom Work email. 
* `101` - Single Sign-On (SSO). 

These login methods are only available in China. 
* `11` - Phone number. 
* `21` - WeChat. 
* `23` - Alipay. |
| `encrypted_email` | boolean |  | Whether the email address passed for the `userId` value is an encrypted email address. 

 * `true` - The email address is encrypted. 
 * `false` - The email address is not encrypted. 

 If you do not query this parameter, this value defaults to null (`false`). |
| `search_by_unique_id` | string |  | Whether the queried `userId` value is an employee unique ID. 
* `true` - The queried ID is an employee&#39;s unique ID. 
* `false` - The queried ID is not an employee&#39;s unique ID. 

This value defaults to `false` (null). |
