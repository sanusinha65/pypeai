### Request Params
| Key | Datatype | Required | Description |
| `login_type` | number |  | The user&#39;s login method. 
* `0` - Facebook OAuth. 
* `1` - Google OAuth. 
* `24` - Apple OAuth. 
* `27` - Microsoft OAuth. 
* `97` - Mobile device. 
* `98` - RingCentral OAuth. 
* `99` - API user. 
* `100` - Zoom Work email. 
* `101` - Single Sign-On (SSO). 

These login methods are only available in China. 
* `11` - Phone number. 
* `21` - WeChat. 
* `23` - Alipay. |
| `remove_tsp_credentials` | string |  | Whether to remove the user&#39;s TSP credentials. 
* `true` - The queried ID is an employee&#39;s unique ID. 
* `false` - The queried ID is not an employee&#39;s unique ID. 

 This value defaults to `false` (null). |
