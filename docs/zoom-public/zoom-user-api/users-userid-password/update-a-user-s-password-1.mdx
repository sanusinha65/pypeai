# Update a user&#39;s password

PUT {{baseUrl}}/users/:userId/password


<p>
Update the 
<a href="https://support.zoom.us/hc/en-us/articles/206344385-Change-a-User-s-Password">
password
</a>
 of a user using which the user can login to Zoom. For user-level apps, pass 
<a href="https://developers.zoom.us/docs/api/rest/using-zoom-apis/#the-me-keyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>
After this request is processed successfully, an email notification is sent to the user saying that the password was changed.  
</p>



<p>

<strong>
Prerequisites:
</strong>
  
</p>



<ul>


<li>
Owner or admin of the Zoom account.
</li>


</ul>



<p>

<strong>
Scopes:
</strong>
 
<code>
user:write:admin
</code>
,
<code>
user:write
</code>

</p>

<strong>

<a href="https://marketplace.zoom.us/docs/api-reference/rate-limits#rate-limits">

</a>
:

Medium
</code>

</p>
