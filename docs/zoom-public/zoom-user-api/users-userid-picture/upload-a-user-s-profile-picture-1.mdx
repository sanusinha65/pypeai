# Upload a user&#39;s profile picture

POST {{baseUrl}}/users/:userId/picture


<p>
Upload a user&#39;s profile picture. For user-level apps, pass 
<a href="https://developers.zoom.us/docs/api/rest/using-zoom-apis/#the-me-keyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>
Provide 
<code>
multipart/form-data
</code>
 as the value of the 
<code>
content-type
</code>
 header for this request. This API supports 
<code>
.jpeg
</code>
 and 
<code>
.png
</code>
 file formats.
</p>



<p>

<strong>
Scopes:
</strong>
 
<code>
user:write:admin

<code>
user:write

</p>

</code>

</p>
