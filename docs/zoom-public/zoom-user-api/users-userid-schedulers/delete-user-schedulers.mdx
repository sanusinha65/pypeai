# Delete user schedulers

DELETE {{baseUrl}}/users/:userId/schedulers


<p>
Delete all of a user&#39;s schedulers. For user-level apps, pass 
<a href="https://developers.zoom.us/docs/api/rest/using-zoom-apis/#the-me-keyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter.
</p>



<p>
Schedulers are users on whose behalf the current user (assistant) can schedule meetings for. By calling this API, the current user will no longer be a scheduling assistant of any user. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* Current user (assistant) must be under the same account as the scheduler.
</p>



<p>

<strong>
Scopes:
</strong>

user:write:admin
</code>
,
<code>
user:write
</code>

</p>
