# Delete Virtual Background files

DELETE {{baseUrl}}/users/:userId/settings/virtual_backgrounds?file_ids=&lt;string&gt;


<p>
Use this API to delete a user&#39;s Virtual Background files. For user-level apps, pass 
<a href="https://marketplace.zoom.us/docs/api-reference/using-zoom-apis#mekeyword">
the 
<code>
me
</code>
 value
</a>
 instead of the 
<code>
userId
</code>
 parameter. 
</p>



<p>

<strong>
Prerequisites:
</strong>
 
* The 
<a href="https://support.zoom.us/hc/en-us/articles/210707503-Virtual-Background#h_2ef28080-fce9-4ac2-b567-dc958afab1b7">
Virtual Background feature
</a>
 must be enabled on the account.
</p>

<strong>

user:write
