#Zoom Video SDK API

Number of APIs: 21


<p>
The Zoom Video SDK API allows owners of Zoom Video SDK accounts to access information from Zoom. You can use this API to build private services or applications. To learn how to get your JWT credentials and create private applications, read our 
<a href="https://marketplace.zoom.us/docs/guides/auth/jwt">
JWT
</a>
 documentation. All endpoints are available via https and are located at api.zoom.us/v2/.
</p>
