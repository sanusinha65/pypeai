# Use in-Session events controls

PATCH {{baseUrl}}/videosdk/sessions/:sessionId/events


<p>
Use this API to control in-Session events such as the 
<strong>
recording controls
</strong>
 to start a recording, stop a recording, pause a recording, and resume a recording, and 
<strong>
invitation control
</strong>
 to invite participants. The recording controls only work for Cloud Recordings and not for local recordings.
</p>



<p>

<strong>
Prerequisite:
</strong>

* The session must be a live session.
* Cloud Recording must be enabled for recording controls.
* The user using this API must either be the host or alternative host of the session.
</p>
