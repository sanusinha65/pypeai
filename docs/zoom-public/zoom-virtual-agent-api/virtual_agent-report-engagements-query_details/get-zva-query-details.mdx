| Key | Datatype | Required | Description |

| `to` | string |  |  The field is **required** only when the **from** parameter is specified. The end time and date is in the **yyyy-mm-dd** or **yyyy-MM-dd&#39;T&#39;HH:mm:ss&#39;Z&#39;** format, which is the same format as the **from** parameter. |
| `timezone` | string |  | The call&#39;s [timezone ID](https://marketplace.zoom.us/docs/api-reference/other-references/abbreviation-lists/#timezones). The default is **UTC**. |
| `page_size` | number |  | The number of items returned per page. 
Constraints: Max: 100 Default: 10 |
| `next_page_token` | string |  | The next page token paginates through a large set of results. A next page token returns whenever the set of available results exceeds the current page size. The expiration period for this token is 15 minutes. |
| `engagement_ids` | string |  | The engagement IDs string separated by &quot;,&quot;. |
