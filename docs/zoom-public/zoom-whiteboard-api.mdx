#Zoom Whiteboard API

Number of APIs: 10


<p>
The Zoom Whiteboard API empowers interactive collaboration by enabling integration with whiteboard features.
</p>



<h5>
Use Cases
</h5>



<ul>


<li>
Create a Zoom Whiteboard user.
</li>


<li>
Facilitate brainstorming sessions with a remote team member.
</li>


<li>
Conduct interactive training or educational sessions online.
</li>


</ul>



1. [whiteboards-{whiteboardId}-collaborator-{collaboratorId} - Remove the collaborator from a whiteboard](https://developers.qodex.ai/zoom-public/zoom-whiteboard-api/whiteboards-whiteboardid-collaborator-collaboratorid/remove-the-collaborator-from-a-whiteboard)
DELETE {{baseUrl}}/whiteboards/:whiteboardId/collaborator/:collaboratorId


2. [whiteboards-{whiteboardId}-collaborator - Share a whiteboard to new users or team chat channels.](https://developers.qodex.ai/zoom-public/zoom-whiteboard-api/whiteboards-whiteboardid-collaborator/share-a-whiteboard-to-new-users-or-team-chat-channels)
